## 三、大数 × 小整数

### 3.1 核心思想

将大数的每一位与小整数相乘，再处理进位。

```
    1 2 3 4
×         7
----------
    8 6 3 8
```

计算过程：

1. 4 × 7 = 28，写 8 进 2
2. 3 × 7 = 21，加进位 2 = 23，写 3 进 2
3. 2 × 7 = 14，加进位 2 = 16，写 6 进 1
4. 1 × 7 = 7，加进位 1 = 8，写 8 进 0

### 3.2 代码实现

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 大数 × 小整数
string multiply(string num, int x) {
    if (x == 0) return "0";

    vector<int> a;
    // 倒序存储大数
    for (int i = num.length() - 1; i >= 0; i--) {
        a.push_back(num[i] - '0');
    }

    vector<int> c;
    int carry = 0;

    for (int i = 0; i < a.size() || carry; i++) {
        int product = carry;
        if (i < a.size()) {
            product += a[i] * x;
        }
        c.push_back(product % 10);
        carry = product / 10;
    }

    // 去除前导零
    while (c.size() > 1 && c.back() == 0) {
        c.pop_back();
    }

    // 转回字符串
    string result = "";
    for (int i = c.size() - 1; i >= 0; i--) {
        result += (char)(c[i] + '0');
    }

    return result;
}

int main() {
    string a;
    int b;
    cin >> a >> b;
    cout << multiply(a, b) << endl;
    return 0;
}
```

### 3.3 关键公式

```cpp
product = a[i] * x + carry;
c[i] = product % 10;
carry = product / 10;
```

**注意**：与加法不同，乘法的 carry 可能大于 1！

## 四、大数 × 大数

### 4.1 回顾小学竖式乘法

```
        1 2 3
    ×     4 5
    ---------
        6 1 5    （123 × 5）
      4 9 2      （123 × 4，左移一位）
    ---------
      5 5 3 5    （相加）
```

### 4.2 核心思想

第二个数的每一位与第一个数相乘，结果累加到对应位置。

**关键公式**：

```
c[i + j] += a[i] * b[j]
```

其中：

- `a[i]` 是第一个数的第 i 位（从 0 开始，低位）
- `b[j]` 是第二个数的第 j 位
- 结果累加到 `c[i + j]` 位置

### 4.3 图示

```
a:     3  2  1     （123 倒序）
b:        5  4     （45 倒序）
-------------------
a[0]*b[0] = 3*5 = 15  → c[0]
a[1]*b[0] = 2*5 = 10  → c[1]
a[2]*b[0] = 1*5 = 5   → c[2]

a[0]*b[1] = 3*4 = 12  → c[1]
a[1]*b[1] = 2*4 = 8   → c[2]
a[2]*b[1] = 1*4 = 4   → c[3]
-------------------
c: 15, 22, 13, 4

处理进位后：5, 3, 5, 5  → 5535
```

### 4.4 代码实现

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 大数 × 大数
string multiply(string num1, string num2) {
    if (num1 == "0" || num2 == "0") return "0";

    int len1 = num1.length();
    int len2 = num2.length();

    // 结果最多 len1 + len2 位
    vector<int> c(len1 + len2, 0);

    // 倒序存储
    vector<int> a, b;
    for (int i = len1 - 1; i >= 0; i--) {
        a.push_back(num1[i] - '0');
    }
    for (int i = len2 - 1; i >= 0; i--) {
        b.push_back(num2[i] - '0');
    }

    // 逐位相乘，累加到对应位置
    for (int i = 0; i < a.size(); i++) {
        for (int j = 0; j < b.size(); j++) {
            c[i + j] += a[i] * b[j];
        }
    }

    // 统一处理进位
    int carry = 0;
    for (int i = 0; i < c.size(); i++) {
        c[i] += carry;
        carry = c[i] / 10;
        c[i] %= 10;
    }

    // 去除前导零
    int len = c.size();
    while (len > 1 && c[len - 1] == 0) {
        len--;
    }

    // 转回字符串
    string result = "";
    for (int i = len - 1; i >= 0; i--) {
        result += (char)(c[i] + '0');
    }

    return result;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << multiply(a, b) << endl;
    return 0;
}
```

### 4.5 另一种写法：边乘边处理进位

```cpp
#include <iostream>
#include <string>
using namespace std;

string multiply(string num1, string num2) {
    if (num1 == "0" || num2 == "0") return "0";

    int len1 = num1.length();
    int len2 = num2.length();

    int c[2010] = {0};  // 存储结果

    // 注意：这里直接使用正序下标，但逻辑是从低位开始
    for (int i = len1 - 1; i >= 0; i--) {
        for (int j = len2 - 1; j >= 0; j--) {
            int mul = (num1[i] - '0') * (num2[j] - '0');
            int p1 = i + j;      // 进位位置
            int p2 = i + j + 1;  // 当前位置

            int sum = mul + c[p2];
            c[p2] = sum % 10;
            c[p1] += sum / 10;
        }
    }

    // 转字符串，跳过前导零
    string result = "";
    for (int i = 0; i < len1 + len2; i++) {
        if (result.empty() && c[i] == 0) continue;
        result += (char)(c[i] + '0');
    }

    return result.empty() ? "0" : result;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << multiply(a, b) << endl;
    return 0;
}
```

## 五、进位处理详解

### 5.1 加法 vs 乘法的进位

| 运算      | 最大单次和/积      | 最大进位     |
| --------- | ------------------ | ------------ |
| 加法      | 9 + 9 + 1 = 19     | 1            |
| 大数×小数 | 9 × 9999 + 进位    | 可能很大     |
| 大数×大数 | 多次累加，可能很大 | 需要多次处理 |

### 5.2 两种处理进位的策略

**策略一**：边乘边进位

```cpp
for (int i = 0; i < a.size(); i++) {
    for (int j = 0; j < b.size(); j++) {
        int sum = c[i + j] + a[i] * b[j];
        c[i + j] = sum % 10;
        c[i + j + 1] += sum / 10;  // 进位
    }
}
```

**策略二**：先累加，最后统一进位（推荐）

```cpp
// 先累加所有乘积
for (int i = 0; i < a.size(); i++) {
    for (int j = 0; j < b.size(); j++) {
        c[i + j] += a[i] * b[j];
    }
}

// 统一处理进位
for (int i = 0; i < maxLen; i++) {
    c[i + 1] += c[i] / 10;
    c[i] %= 10;
}
```

### 例题1：阶乘的精确值

**题目**：求 n!（n 的阶乘）的精确值（1 ≤ n ≤ 100）。

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

string multiply(string num, int x) {
    if (x == 0) return "0";

    vector<int> c;
    int carry = 0;

    for (int i = num.length() - 1; i >= 0 || carry; i--) {
        int product = carry;
        if (i >= 0) {
            product += (num[i] - '0') * x;
        }
        c.push_back(product % 10);
        carry = product / 10;
    }

    string result = "";
    for (int i = c.size() - 1; i >= 0; i--) {
        result += (char)(c[i] + '0');
    }

    return result;
}

int main() {
    int n;
    cin >> n;

    string result = "1";
    for (int i = 2; i <= n; i++) {
        result = multiply(result, i);
    }

    cout << result << endl;

    return 0;
}
```

### 例题3：大数乘大数

**题目**：输入两个大整数，求它们的乘积。

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

string multiply(string num1, string num2) {
    if (num1 == "0" || num2 == "0") return "0";

    int len1 = num1.length();
    int len2 = num2.length();
    vector<int> c(len1 + len2, 0);

    // 逐位相乘
    for (int i = len1 - 1; i >= 0; i--) {
        for (int j = len2 - 1; j >= 0; j--) {
            c[i + j + 1] += (num1[i] - '0') * (num2[j] - '0');
        }
    }

    // 处理进位
    for (int i = c.size() - 1; i > 0; i--) {
        c[i - 1] += c[i] / 10;
        c[i] %= 10;
    }

    // 转字符串
    string result = "";
    bool leadingZero = true;
    for (int i = 0; i < c.size(); i++) {
        if (leadingZero && c[i] == 0) continue;
        leadingZero = false;
        result += (char)(c[i] + '0');
    }

    return result.empty() ? "0" : result;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << multiply(a, b) << endl;
    return 0;
}
```

## 七、常见错误

### 错误1：忘记处理乘以 0

```cpp
// ❌ 忘记特判
string multiply(string num, int x) {
    // 当 x = 0 时，会输出空字符串
}

// ✅ 正确
if (x == 0) return "0";
if (num == "0") return "0";
```

### 错误2：结果数组开得太小

```cpp
// ❌ 两个 100 位的数相乘，结果可能有 200 位！
int c[100];

// ✅ 正确
int c[210];  // 或 vector<int> c(len1 + len2)
```

### 错误3：进位处理不完整

```cpp
// ❌ 循环结束后可能还有进位
for (int i = 0; i < a.size(); i++) {
    // ...
}

// ✅ 正确：循环条件包含 carry
for (int i = 0; i < a.size() || carry; i++) {
    // ...
}
```

## 八、算法复杂度

| 类型               | 时间复杂度 | 说明                  |
| ------------------ | ---------- | --------------------- |
| 大数 × 小整数      | O(n)       | n 是大数的位数        |
| 大数 × 大数 (朴素) | O(n × m)   | n、m 分别是两数的位数 |
| 大数 × 大数 (优化) | O(n log n) | FFT/NTT，竞赛高级算法 |

**本课只讲朴素算法**，足够应对 CSP-J 以及大部分基础题目。

## 九、本课小结

### 核心算法

**大数 × 小整数**：

```
每一位与小整数相乘，累加进位
```

**大数 × 大数**：

```
c[i + j] += a[i] * b[j]
最后统一处理进位
```

### 关键公式

```cpp
// 大数 × 小整数
product = a[i] * x + carry;
c[i] = product % 10;
carry = product / 10;

// 大数 × 大数
c[i + j] += a[i] * b[j];
// 最后统一：c[i+1] += c[i]/10; c[i] %= 10;
```

### 注意事项

- ✅ 结果数组要够大（两数位数之和）
- ✅ 特判乘以 0 的情况
- ✅ 进位可能很大，需要多次处理
- ✅ 去除前导零
