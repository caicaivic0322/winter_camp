## 二、快速排序（Quick Sort）

### 2.1 核心思想

**选一个基准（Pivot），把小的放左边，大的放右边，然后递归处理左右两部分。**

### 2.2 分区操作（Partition）

选择一个基准值，将数组分成两部分：
- 左边的元素都 ≤ Pivot
- 右边的元素都 ≥ Pivot

#### 代码实现（Lomuto 分区）

```cpp
int partition(int arr[], int low, int high) {
    int pivot = arr[high];  // 选最后一个元素为基准
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return i + 1;
}

void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}
```

### 2.3 复杂度与特点

- **平均时间**：O(n log n)
- **最坏时间**：O(n²)
- **空间**：O(log n)
- **特点**：不稳定，但通常比归并排序更快。

## 三、贪心算法（Greedy Algorithm）

### 3.1 什么是贪心？

贪心算法在每一步选择中都采取在当前状态下最好或最优（即最有利）的选择，从而希望导致结果是全局最好或最优的算法。

**核心口诀**：**眼前利益最大化**。

### 3.2 贪心与动态规划的区别

- **贪心**：做完选择就不可撤销，不考虑子问题的交互。
- **动态规划**：会考虑各种可能的选择，保存子问题的解。

### 3.3 经典案例：硬币找零

**问题**：假设有面值为 1, 5, 10, 20, 50, 100 的纸币，要支付 K 元，最少需要多少张？

**策略**：每次都选面值不超过剩余金额的最大纸币。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int money[] = {100, 50, 20, 10, 5, 1};
    int K;
    cin >> K;
    
    int count = 0;
    for (int m : money) {
        while (K >= m) {
            K -= m;
            count++;
            cout << "使用一张 " << m << " 元" << endl;
        }
    }
    cout << "总共需要: " << count << " 张" << endl;
    return 0;
}
```

### 3.4 经典案例：活动选择问题

**问题**：给定 N 个活动的开始时间和结束时间，同一个会议室同一时间只能进行一个活动，最多能安排多少个活动？

**策略**：总是优先选择**结束时间最早**且不冲突的活动。

```cpp
struct Activity {
    int start, end;
};

bool compare(Activity a, Activity b) {
    return a.end < b.end; // 按结束时间升序排序
}

// 核心逻辑
sort(activities, activities + n, compare);
int count = 1;
int last_end = activities[0].end;

for (int i = 1; i < n; i++) {
    if (activities[i].start >= last_end) {
        count++;
        last_end = activities[i].end;
    }
}
```

### 练习 2：饼干分发（贪心）

**题目**：有一群孩子和一堆饼干，每个孩子有一个饥饿度 `g[i]`，每块饼干有一个大小 `s[j]`。如果 `s[j] >= g[i]`，我们可以将饼干 j 给孩子 i，孩子会满足。每个孩子最多只能给一块饼干。求最多能满足多少个孩子。

**思路**：
1. 对孩子饥饿度排序。
2. 对饼干大小排序。
3. 双指针遍历，优先用最小的饼干满足饥饿度最小的孩子。

```cpp
// 请尝试完整实现
sort(g, g + n);
sort(s, s + m);
int child = 0, cookie = 0;
while (child < n && cookie < m) {
    if (s[cookie] >= g[child]) {
        // 满足了，下一个孩子
        child++;
    }
    // 无论是否满足，这块饼干都处理过了（如果太小就扔掉，如果给了就消耗了）
    cookie++;
}
```

## 五、本课小结

1. **快速排序**：分治法的代表，核心是 Partition。
2. **贪心算法**：局部最优推出全局最优，适用于具有"贪心选择性质"的问题。
3. **关键点**：贪心算法并不总能得到全局最优解（例如特定面值的找零问题），需谨慎验证。
