### 第1题：二维数组转置

**题目描述**：给定一个 $3 \times 3$ 的二维数组，将其行列互换（转置）并输出结果。

```cpp
#include <iostream>
using namespace std;

int main() {
    int matrix[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    int transposed[3][3];

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            // 将原数组的第 i 行第 j 列赋值给新数组的第 j 行第 i 列
            transposed[j][i] = ______①;
        }
    }

    // 输出转置后的数组
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            cout << ______② << " ";
        }
        cout << endl;
    }
    return 0;
}
```

**① 的备选项：**
A. `matrix[i][j]`
B. `matrix[j][i]`
C. `matrix[i][i]`
D. `matrix[j][j]`

**② 的备选项：**
A. `matrix[i][j]`
B. `transposed[i][j]`
C. `transposed[j][i]`
D. `i + j`
