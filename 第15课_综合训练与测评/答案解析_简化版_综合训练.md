## 一、单选题

**1. A**
**解析：**
对于任意正整数 $x$，`x & (x - 1)` 的作用是将 $x$ 的二进制原码中最右侧的 `1` 变为 `0`。本题中 $x = 5$，其二进制表示为 `0101`；$x - 1 = 4$，其二进制表示为 `0100`。进行按位与运算：`0101 & 0100 = 0100`，即十进制的 `4`。

**2. B**
**解析：**
在 C++ 中，值传递会拷贝实参的值，在函数内部修改变量仅仅修改了副本体，无法影响函数外面的实参。要想在函数内修改外部变量本身，需要将其地址（指针传递）或者引用（引用传递）传给函数。

**3. B**
**解析：**
在 C++ 中，对于结构体指针访问其成员需要使用指针访问运算符 `->`，即 `p->data`。如果 `p` 是结构体变量本身，才使用 `.` 运算符（类似于 `p.data`）；而对于解引用后再访问可以用 `(*p).data`。选项 B 是最直接和标准的写法。

**4. C**
**解析：**
对于长度为 $N$ 的数组进行冒泡排序，在最坏情况下（例如数组完全逆序），第一趟需要比较 $N-1$ 次，第二趟比较 $N-2$ 次，依次类推，最后一趟比较 $1$ 次。所有比较次数的总和为等差数列求和：$(N-1) + (N-2) + \dots + 1 = \frac{N(N-1)}{2}$，因此选 C。

**5. A**
**解析：**
首先计算括号内部逻辑关系：`4 >= 6` 显然为假（`false`）；判断 `3 != 3` 也是假（`false`）。接着执行逻辑或运算：`false || false` 的结果为假（`false`）。最后外部有一个逻辑非运算符 `!`，对假取反即可得到真（`true`）。

**6. A**
**解析：**
十进制转二进制可采用“除2取余，逆序排列”法：
27 / 2 = 13 ... 余 1
13 / 2 = 6 ... 余 1
6 / 2 = 3 ... 余 0
3 / 2 = 1 ... 余 1
1 / 2 = 0 ... 余 1
将余数从下往上（逆序）排列，结果为 `11011`。

**7. C**
**解析：**
在深度为 $k$ 的满二叉树中，第 $i$ 层拥有 $2^{i-1}$ 个节点。将 1 到 $k$ 层的全部节点数相加求解：$2^0 + 2^1 + 2^2 + \dots + 2^{k-1}$。这是一个等比数列，利用求和公式计算得结果为 $2^k - 1$。

**8. C**
**解析：**
要将单向链表中的节点 `p` 跳过（断开），只需将其前驱节点 `pre` 的指针域直接指向 `p` 节点的后继节点即可，即指向 `p->next`。代码应写作 `pre->next = p->next;`。

**9. B**
**解析：**
首先变量 `a = 10`（二进制表示为 `1010`）。接着执行 `b = a >> 1`，按位右移 1 位等价于整除 2，得 `b = 5`（二进制表示为 `0101`）。最后执行按位异或 `b = b ^ 1`（`1` 二进制为 `0001`）：`0101 ^ 0001 = 0100`，转换为十进制后结果是 `4`。

**10. C**
**解析：**
先计算内层索引 `arr[1]` 的值，数组下标从 0 算起，所以 `arr[1]` 的值为 3。然后外层被解析为 `arr[3]`，对应数组中下标为 3（即第 4 个位置）的元素，其值为 `7`。

**11. B**
**解析：**
A项错误，局部变量的作用范围只限于所在的函数内或代码块。C项错误，局部变量可以和全局变量同名，在函数内部出现同名时，局部变量会“优先并且屏蔽”外部的全局变量。D项错误，全局变量存放在“静态存储区/全局数据区”，而不是栈区（栈区主要存放局部变量以及函数调用时的相关参数）。B项正确，未在代码中显式初始化的全局变量会自动初始化为 0。

**12. B**
**解析：**
变量 `a = 7`, `b = 2`。首先进行求余运算 `7 % 2` 结果为 1。然后进行除法运算 `7 / 2`，因为这是在 C++ 两个整数相除的条件下，因此结果向下取整，得到 3。最终相加：`1 + 3 = 4`。

**13. C**
**解析：**
`sizeof` 是一个获取变量、表达式或具体类型在内存中所需占用的字节空间的单目运算符。对于绝大多数情况，它是在程序的**编译阶段（Compile-Time）**执行并直接替换为常数值的，而非程序运行时（Runtime）计算。因此 C 选项描述错误。

**14. B**
**解析：**
二分查找法在每一次比较之后，都会将未确定的搜索序列一分为二。在最坏情况下，假设查到最后区间长度缩小变为 1，所需的划分次数 $k$ 满足 $2^k = N$，因此时间复杂度是对数级别的 $O(\log N)$。

**15. C**
**解析：**
在 C++ 中，合法的标识符（如变量名、函数名等）只能由英文字母、数字和下划线 `_` 组成，而且不能以数字开头，另外也不能是编译器保留的关键字。A 项错在数字开头，B 项错在使用了非法的减号字符（会被识别成减法运算符），D 项 `int` 是用于声明数据类型的关键字。只有 C 符合规范要求。

## 二、判断题

**1. ✓（对）**
**解析：** 按位异或（XOR）运算的原则是“同为 0，异为 1”。如果两个操作数完全相等，它们对应的每一个二进制位必然也都一致，因此异或之后所得的每一位都是 `0`，结果肯定为 `0`。

**2. ✗（错）**
**解析：** 在 C 语言中，`struct` 通常仅包含数据结构。但在 C++ 语言特性的支持下，`struct` 的功能得到了扩充，它可以像 `class` 一样既包含成员变量，也包含成员函数。`struct` 与 `class` 唯一有实质区别的是它内部成员默认的访问控制权限不同（`struct` 默认是 `public` 公有，`class` 默认是 `private` 私有）。

**3. ✗（错）**
**解析：** 二分查找算法依赖序列存在一定的单调顺序去有效且逐步缩小查找范围，从而大大提高查找效率。因此使用该算法的前提条件是此数组**必须已经按顺序排好（有序）**。对于无序数组，如果不先进行排序是无法正常运用二分查找的。

**4. ✓（对）**
**解析：** 在 C/C++ 语言里，将数组名作为函数的入口实参传给函数时，这个数组名会自动发生退化，传递过去的实际上是被分配该数组在内存中起始位置的指针地址（也就是首元素的地址）。正因如此，通过该首地址在函数内修改数组内容，是能够同步影响原数组的。

**5. ✓（对）**
**解析：** 对于在条件语句中使用的 `&&` 运算结构（按位逻辑与），由于要左右两边全为“真值”时才返回 `true`，只要最先开始判定的左边部分 `A` 被求得为 `false`，则最终整个逻辑式绝对等于假已经成为定局。为了提升运行时的代码执行效率，编译器会直接略去对右侧表达式 `B` 的计算，这种特性就是大家常说的“短路求值（Short-circuit evaluation）”。

## 三、完善程序题

### 第1题：插入排序算法实现

**① `key`**
**解析：**
在此处 `while` 的内层循环中，我们需要为当前准备插入的元素确定正确位置。刚才这个元素被临时暂存保存在了变量 `key` 中。只要我们发现前面的已知排好序的值 `a[j]` 比当前的待插值 `key` 还要大，当前就不是合适的位置，所以需要进入循环将它往后移动。

**② `j + 1`**
**解析：**
此时发现 `a[j]` 大于 `key`，这表示正确的发展趋势应该是要把比 `key` 大的元素统统在数组中往后挪动留出空间存放，也就是把前驱 `a[j]` 挪给紧接着它后一格的 `a[j+1]`，腾出前面的位置才能供后续放入待排序的这个 `key`。

**③ `j + 1`**
**解析：**
在上述 `while` 循环因为遇到不满足条件而结束后，要注意 `j` 因 `j--` 的减量操作已往左边退了一格，此时最新指在的 `j` 这个位置对应的值刚好是个满足 `a[j] <= key` 了的数，这反映正确的空当处于这个数的紧接着下面一格的位置。为了将等待排序好的内容放进去，需赋值给正确的空当位置：`a[j+1]` 里面。

### 第2题：求单链表中的最大值

**① `head->data`**
**解析：**
代码中指针 `current` 在声明时的初始值被从链表的第二个节点赋值开始了（即它指向 `head->next` 去接着往下遍历循环）。那么在整个对剩下所有的节点值循环比较这套流程发生展开前，应当将现在已经先接触并且抓在手里的最初第一格所在节点携带的值，预先存设作为比较基准“目前经历过的最大记录值”。也就是调用出原初头节点的数据初始化一下：`maxVal = head->data;`。

**② `current != NULL`（或直接使用 `current`）**
**解析：**
当遍历查找持续朝深度方向处理时，怎么断定走到尽头了呢。在由指针指代构成的单向链表数据结构当中，由于终点后续连结没有实体节点依靠，这指针在脱离了实际结尾来到最末尾之处必然会取得空值，判定当指针仍然代表一个非空的地址并尚未跌出末端也就是不处于失效空白状态下才可以安全正常抓取信息，也就是判定条件 `current != NULL`。

**③ `current->next`**
**解析：**
既然现在在这个遍历环节中咱们对所停留停留这一轮节点值的判定比对任务已顺利落幕，必须主动作出向后移动。我们就是经过更新这根记录位置指针，使得接下来跳转瞄准该节点的下面所挂链附带着的一个指向：`current = current->next;` 即可将进程过渡迭代入链表之后的节点元素。
