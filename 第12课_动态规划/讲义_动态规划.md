## 二、什么是动态规划？

### 2.1 核心概念

动态规划（Dynamic Programming，简称 DP）通过把原问题分解为相对简单的子问题的方式求解复杂问题。

**关键特征**：
1. **重叠子问题**：子问题会被重复计算（如斐波那契数列）。
2. **最优子结构**：问题的最优解包含其子问题的最优解。
3. **无后效性**：一旦某个状态确定，就不会受未来决策的影响。

### 2.2 入门案例：斐波那契数列

求第 N 项斐波那契数：1, 1, 2, 3, 5, 8...

#### 方法1：递归（暴力）
```cpp
int fib(int n) {
    if (n <= 2) return 1;
    return fib(n-1) + fib(n-2);
}
// 缺点：大量重复计算，O(2^n)
```

#### 方法2：记忆化搜索（自顶向下）
```cpp
int memo[1000];
int fib(int n) {
    if (n <= 2) return 1;
    if (memo[n] != 0) return memo[n]; // 查表
    return memo[n] = fib(n-1) + fib(n-2);
}
// 优化：O(n)
```

#### 方法3：动态规划（自底向上）
```cpp
int dp[1000];
dp[1] = dp[2] = 1;
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i-1] + dp[i-2];
}
// 优化：O(n)
```

## 三、经典问题：爬楼梯

**问题**：假设你正在爬楼梯。需要 n 阶你才能到达楼顶。每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

### 3.1 分析

- 到达第 i 阶，只能从第 i-1 阶跳 1 步，或者从第 i-2 阶跳 2 步而来。
- 所以：`dp[i] = dp[i-1] + dp[i-2]`。
- 初始状态：`dp[1] = 1`, `dp[2] = 2`。

### 3.2 代码实现

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    if (n == 1) { cout << 1; return 0; }
    
    int dp[100];
    dp[1] = 1;
    dp[2] = 2;
    
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    
    cout << dp[n] << endl;
    return 0;
}
```

## 四、经典问题：0/1 背包问题（简介）

**问题**：有 N 件物品和一个容量为 V 的背包。第 i 件物品的体积是 c[i]，价值是 w[i]。每件物品只能用一次，求最大价值。

### 4.1 状态定义

`dp[i][j]` 表示前 i 件物品放入容量为 j 的背包可以获得的最大价值。

### 4.2 状态转移方程

对于第 i 件物品，我们有两种选择：
1. **不放**：`dp[i][j] = dp[i-1][j]`
2. **放**：`dp[i][j] = dp[i-1][j-c[i]] + w[i]` （前提是能放得下，j >= c[i]）

综合：
`dp[i][j] = max(dp[i-1][j], dp[i-1][j-c[i]] + w[i])`

## 五、随堂练习

### 练习 1：最小花费爬楼梯

**题目**：给你一个整数数组 `cost`，其中 `cost[i]` 是从楼梯第 `i` 个台阶向上爬需要支付的费用。一旦你支付此费用，即可选择向上爬一个或者两个台阶。你可以选择从下标为 0 或下标为 1 的台阶开始爬楼梯。请你计算并返回达到楼梯顶部的最低花费。

**提示**：
`dp[i]` 表示到达第 i 阶的最小花费。
`dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`

### 练习 2：最大子数组和

**题目**：给你一个整数数组 `nums`，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**提示**：
`dp[i]` 表示以 `nums[i]` 结尾的最大子数组和。
`dp[i] = max(nums[i], dp[i-1] + nums[i])`
如果 `dp[i-1] < 0`，那么加上它不如不加，直接从 `nums[i]` 开始。

```cpp
int maxSubArray(int nums[], int n) {
    int dp[100]; // 假设 n < 100
    dp[0] = nums[0];
    int maxRes = dp[0];
    for (int i = 1; i < n; i++) {
        dp[i] = max(nums[i], dp[i-1] + nums[i]);
        maxRes = max(maxRes, dp[i]);
    }
    return maxRes;
}
```
