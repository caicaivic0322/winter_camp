# 📝 第2课 答案与解析：二进制与位运算

## 一、选择题（每题5分，共30分）

1. **B**
   **解析**：25 = 16 + 8 + 1 = $2^4 + 2^3 + 2^0$，二进制为 11001。

2. **C**
   **解析**：$1101_2 = 1 \times 2^3 + 1 \times 2^2 + 0 \times 2^1 + 1 \times 2^0 = 8 + 4 + 0 + 1 = 13$。

3. **A**
   **解析**：13 (1101) & 7 (0111) = 0101 = 5。按位与运算：全1为1，否则为0。

4. **D**
   **解析**：5 (101) | 3 (011) = 111 = 7。按位或运算：有1为1，全0为0。

5. **B**
   **解析**：左移运算符 `<<` 相当于乘以 $2^k$。$5 \times 2^2 = 5 \times 4 = 20$。

6. **B**
   **解析**：判断奇偶最快的方法是判断最低位是否为1。`n % 2` 较慢，`n & 1` 直接检查二进制最低位，效率最高。

## 二、判断题（每题5分，共20分）

1. **√**
   **解析**：在计算机中，正数的原码、反码和补码形式完全相同。

2. **√**
   **解析**：`n-1` 会把 `n` 最低位的 1 变成 0，并将该位右边的 0 变成 1。`n & (n-1)` 正好能消除最低位的 1。

3. **√**
   **解析**：异或运算性质：同位相同为0，不同为1。任何数与自己异或结果均为 0。

4. **×**
   **解析**：位运算符的优先级通常**低于**算术运算符（加减乘除）。例如 `a + b << 1` 会先算加法。

## 三、程序完善题（每题25分，共50分）

### 第1题

① `0`
② `n` （或 `n != 0`）
③ `count++`
④ `n >> 1`
⑤ `count`

**解析**：

- ① 计数器初始化为 0。
- ② 循环条件：当 `n` 不为 0 时继续。
- ③ 如果最低位是 1（`n & 1` 为真），计数器加 1。
- ④ 右移一位，检查下一位。
- ⑤ 返回计数结果。

### 第2题

① `n`
② `k`
③ `&`

**解析**：

- 此题目的是提取 `n` 的第 `k` 位。
- `n >> k` 将第 `k` 位移到最低位。
- 再与 `1` 进行按位与运算 `& 1`，即可取出该位的值（0或1）。
