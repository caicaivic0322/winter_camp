# 📘 第11章 二维数组

> 目标：掌握二维数组的声明、访问与常见操作

---

## 11.1 概念与声明
```cpp
int a[3][4];                  // 3 行 4 列
int b[2][3] = {{1,2,3},{4,5,6}};
cout << b[1][2] << endl;      // 输出 6
```
- 连续存储，按行优先（row-major）

---

## 11.2 应用实例：矩阵行列和
```cpp
int n, m; cin >> n >> m;
int sRow[110]={0}, sCol[110]={0};
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        int x; cin >> x;
        sRow[i] += x; sCol[j] += x;
    }
}
for (int i = 0; i < n; i++) cout << sRow[i] << " ";
cout << "\n";
for (int j = 0; j < m; j++) cout << sCol[j] << " ";
```
