## 二、回顾：分治与树的关系

### 2.1 归并排序的递归树

```
          [5,2,4,6,1,3]
         /              \
    [5,2,4]           [6,1,3]
    /     \           /     \
  [5,2]  [4]       [6,1]   [3]
  /   \            /   \
[5]  [2]         [6]  [1]
```

### 2.2 这就是后序遍历！

归并排序 = **先处理左右子树，最后处理根**

```cpp
void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;

    mergeSort(l, mid);      // 处理左子树
    mergeSort(mid + 1, r);  // 处理右子树
    merge(l, mid, r);       // 处理根（合并）
}
```

## 三、归并排序的核心：合并

### 3.1 合并两个有序数组

```
左数组：[2, 5]
右数组：[1, 4]
结果：  []

步骤1：比较 2 和 1，1 更小 → [1]
步骤2：比较 2 和 4，2 更小 → [1, 2]
步骤3：比较 5 和 4，4 更小 → [1, 2, 4]
步骤4：右数组用完，5 直接加入 → [1, 2, 4, 5]
```

## 四、代码实现

```cpp
#include <iostream>
using namespace std;

int temp[100];

void merge(int arr[], int l, int mid, int r) {
    int i = l, j = mid + 1, k = l;

    while (i <= mid && j <= r) {
        if (arr[i] <= arr[j]) temp[k++] = arr[i++];
        else temp[k++] = arr[j++];
    }

    while (i <= mid) temp[k++] = arr[i++];
    while (j <= r) temp[k++] = arr[j++];

    for (int i = l; i <= r; i++) arr[i] = temp[i];
}

void mergeSort(int arr[], int l, int r) {
    if (l >= r) return;

    int mid = (l + r) / 2;
    mergeSort(arr, l, mid);      // 排序左半部分
    mergeSort(arr, mid + 1, r);  // 排序右半部分
    merge(arr, l, mid, r);       // 合并
}

int main() {
    int arr[] = {5, 2, 4, 6, 1, 3};
    int n = 6;

    mergeSort(arr, 0, n - 1);

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    return 0;
}
```

## 五、时间复杂度

### 5.1 递归树分析

- 每一层的合并代价：O(n)
- 树的高度：O(log n)
- **总时间**：O(n log n)

### 5.2 与 O(n²) 对比

| n      | O(n²)       | O(n log n) |
| ------ | ----------- | ---------- |
| 1000   | 1,000,000   | 10,000     |
| 10,000 | 100,000,000 | 130,000    |

## 六、特点总结

| 特性       | 值                 |
| ---------- | ------------------ |
| 时间复杂度 | O(n log n)（稳定） |
| 空间复杂度 | O(n)               |
| 稳定性     | 稳定               |
| 适用场景   | 大规模数据、链表   |

---

## 七、与快速排序对比

| 特性       | 归并排序        | 快速排序        |
| ---------- | --------------- | --------------- |
| 遍历方式   | 后序（分→合）   | 前序（处理→分） |
| 时间稳定性 | 稳定 O(n log n) | 最坏 O(n²)      |
| 空间       | O(n)            | O(log n)        |
| 排序稳定性 | 稳定            | 不稳定          |
