## 二、什么是哈希表？

### 2.1 查找的困境

思考：如何在海量数据中快速找到某个值？

- **数组**：需要遍历，时间复杂度 O(n)
- **链表**：同样需要遍历，时间复杂度 O(n)
- **排序数组**：二分查找 O(log n)，但需要排序

**理想情况**：能否像数组下标访问一样快？→ **哈希表 O(1)**

### 2.2 哈希表的核心思想

```
键(Key) → 哈希函数 → 存储位置(Index) → 取出值(Value)
```

**例子**：存储学生成绩

| 学生姓名 | 哈希值(首字母) | 存储位置 |
| -------- | -------------- | -------- |
| 张三     | Z → 25         | arr[25]  |
| 李四     | L → 11         | arr[11]  |
| 王五     | W → 22         | arr[22]  |

通过姓名直接计算存储位置，**一步到位**！

## 三、哈希函数

### 3.1 什么是哈希函数？

将任意长度的输入（键）转换为固定长度的输出（哈希值）的函数。

```
h(key) → hash value (整数)
```

### 3.2 常见哈希函数

**1. 直接定址法**
```cpp
int hash(int key) {
    return key;  // hash[key] = value
}
```

**2. 除留余数法**（最常用）
```cpp
int hash(int key) {
    return key % MOD;  // MOD 通常取素数
}
```

**3. 平方取中法**
```cpp
int hash(int key) {
    int square = key * key;
    return (square / 100) % 1000;  // 取中间三位
}
```

**4. 字符串哈希**
```cpp
int stringHash(const string& s) {
    int hash = 0;
    for (char c : s) {
        hash = hash * 31 + c;  // 31 是常用的进制数
    }
    return hash;
}
```

### 3.3 好的哈希函数特点

- ✅ 计算速度快
- ✅ 哈希值分布均匀
- ✅ 冲突少

## 四、哈希冲突

### 4.1 什么是哈希冲突？

不同的键计算出相同的哈希值：

```
h("张三") = 5
h("赵六") = 5  // 冲突！
```

### 4.2 冲突处理方法

#### 方法一：链地址法（拉链法）

每个位置存储一个链表，冲突的元素挂在后面：

```
数组下标:  0      1      2      3      4
        [链表] [链表] [链表] [链表] [链表]
           ↑      ↑      ↑
          冲突   冲突   冲突
         元素1  元素2  元素3
```

**插入**：
```cpp
void insert(Node* hashTable[], int size, int key, int value) {
    int idx = hash(key) % size;
    Node* newNode = new Node(key, value);
    newNode->next = hashTable[idx];  // 头插法
    hashTable[idx] = newNode;
}
```

**查找**：
```cpp
int* search(Node* hashTable[], int size, int key) {
    int idx = hash(key) % size;
    Node* cur = hashTable[idx];
    while (cur != nullptr) {
        if (cur->key == key) return &cur->value;
        cur = cur->next;
    }
    return nullptr;  // 未找到
}
```

#### 方法二：开放定址法

冲突时寻找下一个空位置：

```
线性探测: h(key), h(key)+1, h(key)+2, ...
二次探测: h(key), h(key)+1², h(key)+2², ...
```

**插入**：
```cpp
void insert(int hashTable[], int size, int key, int value) {
    int idx = key % size;
    int i = 0;
    while (hashTable[(idx + i) % size] != -1) {
        i++;  // 探测下一个位置
    }
    hashTable[(idx + i) % size] = value;
}
```

## 五、时间复杂度分析

### 5.1 理想情况 vs 最坏情况

| 操作     | 理想情况 | 最坏情况   |
| -------- | -------- | ---------- |
| 查找     | O(1)     | O(n)       |
| 插入     | O(1)     | O(n)       |
| 删除     | O(1)     | O(n)       |

**最坏情况**：所有元素都哈希到同一个位置，退化成链表

### 5.2 负载因子

```
负载因子 = 元素数量 / 哈希表大小
```

- 负载因子 **< 0.5**：查找快，内存利用率低
- 负载因子 **≈ 0.75**：平衡（Java/ C++ STL 默认）
- 负载因子 **> 1**：冲突增多，性能下降

**扩容**：当负载因子超过阈值时，扩容哈希表并重新哈希

## 六、手写哈希表（链地址法）

### 6.1 节点定义

```cpp
struct Node {
    int key;
    int value;
    Node* next;
    
    Node(int k, int v) : key(k), value(v), next(nullptr) {}
};
```

### 6.2 完整代码

```cpp
#include <iostream>
using namespace std;

const int TABLE_SIZE = 10;

struct Node {
    int key;
    int value;
    Node* next;
    
    Node(int k, int v) : key(k), value(v), next(nullptr) {}
};

class HashTable {
private:
    Node* table[TABLE_SIZE];
    
    int hash(int key) {
        return key % TABLE_SIZE;
    }
    
public:
    HashTable() {
        for (int i = 0; i < TABLE_SIZE; i++) {
            table[i] = nullptr;
        }
    }
    
    void insert(int key, int value) {
        int idx = hash(key);
        Node* newNode = new Node(key, value);
        newNode->next = table[idx];
        table[idx] = newNode;
    }
    
    int* search(int key) {
        int idx = hash(key);
        Node* cur = table[idx];
        while (cur != nullptr) {
            if (cur->key == key) return &cur->value;
            cur = cur->next;
        }
        return nullptr;
    }
    
    void remove(int key) {
        int idx = hash(key);
        Node* cur = table[idx];
        Node* prev = nullptr;
        
        while (cur != nullptr) {
            if (cur->key == key) {
                if (prev == nullptr) {
                    table[idx] = cur->next;
                } else {
                    prev->next = cur->next;
                }
                delete cur;
                return;
            }
            prev = cur;
            cur = cur->next;
        }
    }
    
    void display() {
        for (int i = 0; i < TABLE_SIZE; i++) {
            cout << i << ": ";
            Node* cur = table[i];
            while (cur != nullptr) {
                cout << "(" << cur->key << "," << cur->value << ") ";
                cur = cur->next;
            }
            cout << endl;
        }
    }
};

int main() {
    HashTable ht;
    
    ht.insert(1, 100);
    ht.insert(11, 200);  // 冲突: 11 % 10 = 1
    ht.insert(21, 300);  // 冲突: 21 % 10 = 1
    ht.insert(5, 500);
    ht.insert(15, 600);  // 冲突: 15 % 10 = 5
    
    cout << "哈希表内容：" << endl;
    ht.display();
    
    cout << "\n查找 key=11: ";
    int* result = ht.search(11);
    if (result) cout << "value = " << *result << endl;
    else cout << "未找到" << endl;
    
    cout << "查找 key=7: ";
    result = ht.search(7);
    if (result) cout << "value = " << *result << endl;
    else cout << "未找到" << endl;
    
    return 0;
}
```

2: 
3: 
4:

6:

查找 key=11: value = 200
查找 key=7: 未找到

## 八、总结

| 概念       | 要点                               |
| ---------- | ---------------------------------- |
| 哈希函数   | 将键转换为索引的函数               |
| 哈希冲突   | 不同键得到相同索引                 |
| 链地址法   | 冲突位置挂链表                     |
| 开放定址法 | 冲突时寻找下一个空位置             |
| 时间复杂度 | 平均 O(1)，最坏 O(n)               |
