## 二、高精度减法的难点

### 2.1 与加法相比，减法多了什么问题？

| 问题      | 加法         | 减法         |
| --------- | ------------ | ------------ |
| 大小关系  | 不需要考虑   | 需要判断大小 |
| 借位/进位 | 进位最大1    | 借位影响多位 |
| 前导零    | 几乎不用处理 | 必须处理     |
| 结果符号  | 总是正数     | 可能是负数   |

### 2.2 减法的三大"坑"

1. **坑一**：被减数 < 减数 → 结果是负数
2. **坑二**：借位可能连续传递（如 1000 - 1）
3. **坑三**：结果可能有前导零（如 1000 - 999 = 0001）

## 三、核心思想：模拟竖式减法

### 3.1 回顾小学竖式减法

```
    5 0 3 2
  -   1 8 7
  ---------
    4 8 4 5
```

计算过程：

1. 个位：2 - 7，不够减，借 1 → (12 - 7 = 5)
2. 十位：3 - 1(借位) = 2，2 - 8，不够减，借 1 → (12 - 8 = 4)
3. 百位：0 - 1(借位) = -1，不够，借 1 → (10 - 1 = 9)，9 - 1 = 8
4. 千位：5 - 1(借位) = 4

### 3.2 借位的本质

当某一位不够减时：

- 向高位借 1（相当于借 10）
- 本位加 10 后再减

```cpp
if (a[i] < b[i]) {
    a[i] += 10;    // 本位加 10
    a[i + 1]--;    // 高位减 1（借位）
}
c[i] = a[i] - b[i];
```

## 四、关键步骤解析

### 4.1 步骤一：比较大小

因为我们的算法只处理 a ≥ b 的情况，所以需要先比较大小。

```cpp
// 比较两个大数的大小
// 返回：1 表示 a > b，0 表示 a == b，-1 表示 a < b
int compare(string a, string b) {
    // 去除前导零后比较位数
    if (a.length() != b.length()) {
        return a.length() > b.length() ? 1 : -1;
    }
    // 位数相同，逐位比较
    for (int i = 0; i < a.length(); i++) {
        if (a[i] != b[i]) {
            return a[i] > b[i] ? 1 : -1;
        }
    }
    return 0;  // 相等
}
```

### 4.2 步骤二：确保大数减小数

```cpp
string subtract(string a, string b) {
    bool negative = false;

    if (compare(a, b) < 0) {
        swap(a, b);         // 交换，确保 a >= b
        negative = true;    // 标记结果为负
    }

    // 后续计算 a - b（此时 a >= b）
    // ...

    if (negative) {
        result = "-" + result;
    }
    return result;
}
```

### 4.3 步骤三：逐位相减并处理借位

```cpp
int borrow = 0;  // 借位

for (int i = 0; i < len; i++) {
    int diff = a[i] - b[i] - borrow;

    if (diff < 0) {
        diff += 10;      // 借位
        borrow = 1;      // 记录借位
    } else {
        borrow = 0;      // 清除借位
    }

    c[i] = diff;
}
```

### 4.4 步骤四：去除前导零

```cpp
// 去除前导零（但保留至少一位）
while (len > 1 && c[len - 1] == 0) {
    len--;
}
```

**注意**：结果为 0 时，不能全部去掉！

## 五、完整代码实现

### 5.1 版本一：使用数组

```cpp
#include <iostream>
#include <string>
#include <cstring>
using namespace std;

// 比较大小：a > b 返回 1，a == b 返回 0，a < b 返回 -1
int compare(string a, string b) {
    if (a.length() != b.length()) {
        return a.length() > b.length() ? 1 : -1;
    }
    return a.compare(b);  // 字典序比较
}

string subtract(string a, string b) {
    bool negative = false;

    // 确保 a >= b
    if (compare(a, b) < 0) {
        swap(a, b);
        negative = true;
    }

    // 特判相等
    if (compare(a, b) == 0) {
        return "0";
    }

    // 转为数组（倒序）
    int arrA[1010] = {0}, arrB[1010] = {0}, arrC[1010] = {0};
    int lenA = a.length();
    int lenB = b.length();

    for (int i = 0; i < lenA; i++) {
        arrA[i] = a[lenA - 1 - i] - '0';
    }
    for (int i = 0; i < lenB; i++) {
        arrB[i] = b[lenB - 1 - i] - '0';
    }

    // 逐位相减
    int len = lenA;
    int borrow = 0;

    for (int i = 0; i < len; i++) {
        int diff = arrA[i] - arrB[i] - borrow;

        if (diff < 0) {
            diff += 10;
            borrow = 1;
        } else {
            borrow = 0;
        }

        arrC[i] = diff;
    }

    // 去除前导零
    while (len > 1 && arrC[len - 1] == 0) {
        len--;
    }

    // 转回字符串
    string result = "";
    for (int i = len - 1; i >= 0; i--) {
        result += (char)(arrC[i] + '0');
    }

    if (negative) {
        result = "-" + result;
    }

    return result;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << subtract(a, b) << endl;
    return 0;
}
```

### 5.2 版本二：使用 vector

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 比较两个 vector（已倒序存储）
// a > b 返回 true
bool isGreaterOrEqual(vector<int>& a, vector<int>& b) {
    if (a.size() != b.size()) {
        return a.size() > b.size();
    }
    for (int i = a.size() - 1; i >= 0; i--) {
        if (a[i] != b[i]) {
            return a[i] > b[i];
        }
    }
    return true;  // 相等
}

vector<int> subtract(vector<int> a, vector<int> b) {
    vector<int> c;
    int borrow = 0;

    for (int i = 0; i < a.size(); i++) {
        int diff = a[i] - borrow;
        if (i < b.size()) {
            diff -= b[i];
        }

        if (diff < 0) {
            diff += 10;
            borrow = 1;
        } else {
            borrow = 0;
        }

        c.push_back(diff);
    }

    // 去除前导零
    while (c.size() > 1 && c.back() == 0) {
        c.pop_back();
    }

    return c;
}

vector<int> stringToVec(string s) {
    vector<int> v;
    for (int i = s.length() - 1; i >= 0; i--) {
        v.push_back(s[i] - '0');
    }
    return v;
}

string vecToString(vector<int> v) {
    string s = "";
    for (int i = v.size() - 1; i >= 0; i--) {
        s += (char)(v[i] + '0');
    }
    return s;
}

int main() {
    string s1, s2;
    cin >> s1 >> s2;

    vector<int> a = stringToVec(s1);
    vector<int> b = stringToVec(s2);

    if (!isGreaterOrEqual(a, b)) {
        swap(a, b);
        cout << "-";
    }

    vector<int> c = subtract(a, b);
    cout << vecToString(c) << endl;

    return 0;
}
```

## 六、易错点专项

### 6.1 错误一：借位链

**问题**：1000 - 1 = 999

```
借位过程：
1000
-  1
----
从个位开始：0-1 不够，借位
但十位是 0，没法借...
继续向更高位借！
```

**正确处理**：借位会自动传递

```cpp
for (int i = 0; i < len; i++) {
    int diff = a[i] - b[i] - borrow;  // borrow 会传递
    if (diff < 0) {
        diff += 10;
        borrow = 1;  // 借位传递给下一位
    } else {
        borrow = 0;
    }
    c[i] = diff;
}
```

### 6.2 错误二：0 - 0 结果处理

**问题**：输入 "5" 和 "5"，输出应该是 "0"，不是空字符串

```cpp
// 特判
if (compare(a, b) == 0) {
    return "0";
}

// 或者在去除前导零时保留一位
while (len > 1 && c[len - 1] == 0) {  // 注意是 len > 1
    len--;
}
```

### 6.3 错误三：a < b 时的处理

**问题**：输入 "5" 和 "12"，应该输出 "-7"

```cpp
if (compare(a, b) < 0) {
    swap(a, b);      // 交换后变成 12 - 5
    negative = true; // 标记为负数
}

// 最后添加负号
if (negative) {
    result = "-" + result;
}
```

### 6.4 错误四：前导零未去除

**问题**：100 - 99 = 001（应该是 1）

```cpp
// 去除前导零
while (len > 1 && c[len - 1] == 0) {
    len--;
}
```

### 例题2：判断能否相减为正

**题目**：输入两个大整数，判断第一个数减去第二个数是否为正数。

```cpp
#include <iostream>
#include <string>
using namespace std;

int compare(string a, string b) {
    if (a.length() != b.length()) {
        return a.length() > b.length() ? 1 : -1;
    }
    return a.compare(b);
}

int main() {
    string a, b;
    cin >> a >> b;

    int cmp = compare(a, b);
    if (cmp > 0) {
        cout << "正数" << endl;
    } else if (cmp == 0) {
        cout << "零" << endl;
    } else {
        cout << "负数" << endl;
    }

    return 0;
}
```

### 例题3：求绝对值

**题目**：输入两个大整数 A 和 B，输出 |A - B|（差的绝对值）。

```cpp
#include <iostream>
#include <string>
using namespace std;

int compare(string a, string b) {
    if (a.length() != b.length()) {
        return a.length() > b.length() ? 1 : -1;
    }
    return a.compare(b);
}

string subtract(string a, string b) {
    // 确保 a >= b
    if (compare(a, b) < 0) {
        swap(a, b);
    }

    if (compare(a, b) == 0) return "0";

    int arrA[1010] = {0}, arrB[1010] = {0}, arrC[1010] = {0};
    int lenA = a.length(), lenB = b.length();

    for (int i = 0; i < lenA; i++) arrA[i] = a[lenA - 1 - i] - '0';
    for (int i = 0; i < lenB; i++) arrB[i] = b[lenB - 1 - i] - '0';

    int len = lenA, borrow = 0;
    for (int i = 0; i < len; i++) {
        int diff = arrA[i] - arrB[i] - borrow;
        if (diff < 0) { diff += 10; borrow = 1; }
        else { borrow = 0; }
        arrC[i] = diff;
    }

    while (len > 1 && arrC[len - 1] == 0) len--;

    string result = "";
    for (int i = len - 1; i >= 0; i--) result += (char)(arrC[i] + '0');

    return result;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << subtract(a, b) << endl;  // 输出绝对值（无负号）
    return 0;
}
```

## 八、高精度加减法对比

| 操作      | 加法                      | 减法                            |
| --------- | ------------------------- | ------------------------------- |
| 预处理    | 无需比较大小              | 需要比较大小                    |
| 核心运算  | sum = a[i] + b[i] + carry | diff = a[i] - b[i] - borrow     |
| 进位/借位 | carry = sum / 10          | if (diff < 0) borrow = 1        |
| 当前位    | c[i] = sum % 10           | c[i] = (diff + 10) % 10 或 diff |
| 后处理    | 处理最后进位              | 去除前导零                      |
| 结果符号  | 始终为正                  | 可能为负                        |

## 九、本课小结

### 核心算法

```
高精度减法 = 比较大小 + 确保大减小 + 逐位相减 + 处理借位 + 去除前导零
```

### 关键公式

```cpp
int diff = a[i] - b[i] - borrow;
if (diff < 0) {
    diff += 10;
    borrow = 1;
} else {
    borrow = 0;
}
c[i] = diff;
```

### 易错点

- ✅ 必须先比较大小
- ✅ 借位可能连续传递
- ✅ 必须去除前导零
- ✅ 注意 0 - 0 = 0
