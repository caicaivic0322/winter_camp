# 📝 第5课 答案与解析：高精度减法

## 一、选择题（每题5分，共30分）

1. **B**
   **解析**：减法比加法复杂的地方在于需要比较两个数的大小（决定结果符号），以及处理借位（不够减时向高位借 1 当 10）。

2. **C**
   **解析**：计算 $1003 - 7$：
   - 个位 3-7 不够，向十位借，十位是 0，向百位借，百位是 0，向千位借。
   - 借位传递过程：个位←十位←百位←千位。共发生 3 次借位。

3. **C**
   **解析**：比较大数时，先比较位数。位数多的数一定大（如 5 位数 > 4 位数）。位数相同时才从高位开始逐位比较。

4. **B**
   **解析**：当前位原本是 3，被低位借走 1 剩 2，再减去 5 不够减，向高位借 1 当 10，变成 12-5=7。代码逻辑通常是 `diff = A[i] - B[i] - borrow`; `3 - 5 - 1 = -3`; `if diff < 0 { diff += 10; borrow = 1 }` -> `-3 + 10 = 7`。

5. **B**
   **解析**：减法结果可能出现前导零（例如 $100 - 99 = 001$），需要循环判断最高位是否为 0 并移除，直到只剩一位（结果为 0 时保留）。

6. **B**
   **解析**：$100 - 100 = 0$。如果不处理前导零会输出 "000"，处理后应输出 "0"。结果不能为空字符串。

## 二、判断题（每题5分，共20分）

1. **×**
   **解析**：借位可能连续发生，例如 $1000 - 1$，个位不够向十位借，十位不够向百位借，依此类推。一个减法操作可能触发连锁借位。

2. **√**
   **解析**：减法运算后，结果如果是 0，去除前导零后应保留一个 '0'。

3. **√**
   **解析**：和加法一样，为了对齐个位（最小有效位），通常将大数倒序存储在数组中。

4. **√**
   **解析**：位数相同的大数比较，从最高位开始，第一对不相同的数字决定了整体的大小（例如 123**5**0 > 123**4**9）。

## 三、程序完善题（每题25分，共50分）

### 第1题

① `0`
② `borrow`
③ `<`
④ `1`
⑤ `len - 1`

**解析**：

- ① 初始化借位 `borrow` 为 0。
- ② 减法公式：`A[i] - B[i] - borrow`。
- ③ 判断不够减：`diff < 0`。
- ④ 如果不够减，标记下一位需要借位 `borrow = 1`。
- ⑤ 去除前导零时，检查最高位 `arrC[len - 1]`。

### 第2题

① `length`
② `>`
③ `length`
④ `b[i]`
⑤ `0`

**解析**：

- ① 比较长度。
- ② 长度长的数大。
- ③ 长度相同，从高位（下标0开始）遍历到末尾。
- ④ 比较当前位 `a[i]` 和 `b[i]`。
- ⑤ 如果所有位都相等，则两数相等，返回 0。
