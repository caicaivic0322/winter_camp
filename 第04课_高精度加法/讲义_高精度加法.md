## 二、为什么需要高精度？

### 2.1 普通整数的局限

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 2147483647;      // int 最大值
    cout << a + 1 << endl;   // 溢出！输出 -2147483648

    long long b = 9223372036854775807LL;  // long long 最大值
    cout << b + 1 << endl;   // 溢出！

    return 0;
}
```

**问题**：当数字超过数据类型的表示范围时，会发生溢出！

### 2.2 什么情况需要高精度？

- 计算 100! = 93326215443944152681699238856...（158 位数）
- 两个 1000 位的大整数相加
- 密码学中的大数运算

### 2.3 解决思路

既然计算机的基本类型存不下，我们就用数组来存储每一位！

```
大数：123456789012345678901234567890
数组：[0,9,8,7,6,5,4,3,2,1,0,9,8,7,6,5,4,3,2,1,0,9,8,7,6,5,4,3,2,1]
      个位 十位 ...                                              高位
```

## 三、核心思想：模拟竖式加法

### 3.1 回顾小学竖式加法

```
    1 2 3 4
  +   5 6 7
  ---------
    1 8 0 1
```

计算过程：

1. 个位：4 + 7 = 11，写 1 进 1
2. 十位：3 + 6 + 1(进位) = 10，写 0 进 1
3. 百位：2 + 5 + 1(进位) = 8，写 8 进 0
4. 千位：1 + 0 + 0(进位) = 1，写 1

### 3.2 程序模拟的关键点

| 要点         | 说明                                             |
| ------------ | ------------------------------------------------ |
| 倒序存储     | 个位在 a[0]，方便对齐和处理进位                  |
| 逐位相加     | 从低位到高位依次计算                             |
| 处理进位     | sum >= 10 时，进位 = sum / 10，当前位 = sum % 10 |
| 处理不同位数 | 短的数高位补 0                                   |

### 3.3 图示

```
        a:  9  8  7  6  5  4  3  2  1    （987654321 倒序）
        b:        8  7  6  5  4  3  2    （ 87654321 倒序）
  ----------------------------------------
  进位 carry:   1  1  1  1  1  1  1  0
  ----------------------------------------
  结果 c:  5  7  4  3  2  1  0  9  7  1  （1075308642 倒序）
```

## 四、代码实现

### 4.1 版本一：使用字符串（更接近真实输入）

```cpp
#include <iostream>
#include <string>
using namespace std;

// 高精度加法
string add(string num1, string num2) {
    // 1. 将字符串转为数组（倒序）
    int a[1010] = {0}, b[1010] = {0}, c[1010] = {0};
    int len1 = num1.length();
    int len2 = num2.length();

    for (int i = 0; i < len1; i++) {
        a[i] = num1[len1 - 1 - i] - '0';
    }
    for (int i = 0; i < len2; i++) {
        b[i] = num2[len2 - 1 - i] - '0';
    }

    // 2. 逐位相加
    int len = max(len1, len2);
    int carry = 0;  // 进位

    for (int i = 0; i < len; i++) {
        int sum = a[i] + b[i] + carry;
        c[i] = sum % 10;      // 当前位
        carry = sum / 10;     // 进位
    }

    // 3. 处理最高进位
    if (carry > 0) {
        c[len] = carry;
        len++;
    }

    // 4. 转回字符串（倒序输出）
    string result = "";
    for (int i = len - 1; i >= 0; i--) {
        result += (char)(c[i] + '0');
    }

    return result;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << add(a, b) << endl;
    return 0;
}
```

### 4.2 版本二：使用 vector（更简洁）

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 字符串转 vector（倒序）
vector<int> stringToVec(string s) {
    vector<int> v;
    for (int i = s.length() - 1; i >= 0; i--) {
        v.push_back(s[i] - '0');
    }
    return v;
}

// vector 转字符串
string vecToString(vector<int> v) {
    string s = "";
    for (int i = v.size() - 1; i >= 0; i--) {
        s += (char)(v[i] + '0');
    }
    return s;
}

// 高精度加法
vector<int> add(vector<int> a, vector<int> b) {
    vector<int> c;
    int carry = 0;

    for (int i = 0; i < a.size() || i < b.size() || carry; i++) {
        int sum = carry;
        if (i < a.size()) sum += a[i];
        if (i < b.size()) sum += b[i];
        c.push_back(sum % 10);
        carry = sum / 10;
    }

    return c;
}

int main() {
    string s1, s2;
    cin >> s1 >> s2;

    vector<int> a = stringToVec(s1);
    vector<int> b = stringToVec(s2);
    vector<int> c = add(a, b);

    cout << vecToString(c) << endl;
    return 0;
}
```

### 4.3 版本三：使用数组函数封装

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 1010;

// 高精度加法：c = a + b
// 数组第 0 位存长度
void add(int a[], int b[], int c[]) {
    int lenA = a[0], lenB = b[0];
    int len = max(lenA, lenB);
    int carry = 0;

    for (int i = 1; i <= len; i++) {
        int sum = carry;
        if (i <= lenA) sum += a[i];
        if (i <= lenB) sum += b[i];
        c[i] = sum % 10;
        carry = sum / 10;
    }

    if (carry > 0) {
        len++;
        c[len] = carry;
    }

    c[0] = len;  // 存储结果长度
}

// 字符串转数组
void stringToArray(string s, int a[]) {
    int len = s.length();
    a[0] = len;  // 第 0 位存长度
    for (int i = 1; i <= len; i++) {
        a[i] = s[len - i] - '0';  // 倒序存入
    }
}

// 输出数组
void printArray(int a[]) {
    for (int i = a[0]; i >= 1; i--) {
        cout << a[i];
    }
    cout << endl;
}

int main() {
    string s1, s2;
    cin >> s1 >> s2;

    int a[MAXN] = {0}, b[MAXN] = {0}, c[MAXN] = {0};
    stringToArray(s1, a);
    stringToArray(s2, b);
    add(a, b, c);
    printArray(c);

    return 0;
}
```

## 五、关键细节解析

### 5.1 为什么要倒序存储？

**对齐方便**：两个不同位数的数相加时，个位自动对齐。

```
正序存储（不好）：     倒序存储（好）：
a: 1 2 3              a: 3 2 1
b: 4 5                b: 5 4
   ↓ 怎么对齐？          ↓ 自动对齐！
```

**进位方便**：进位总是向数组下标更大的方向传递。

### 5.2 进位处理公式

对于每一位：

```cpp
int sum = a[i] + b[i] + carry;  // 两位相加，加上进位
c[i] = sum % 10;                 // 当前位的结果
carry = sum / 10;                // 新的进位
```

示例：8 + 7 + 1（进位）= 16

- 当前位：16 % 10 = 6
- 进位：16 / 10 = 1

### 5.3 最后的进位不要忘！

```cpp
// 循环结束后，如果还有进位
if (carry > 0) {
    c[len] = carry;
    len++;
}
```

示例：999 + 1 = 1000

- 最后一位相加产生的进位不能丢！

### 5.4 字符与数字的转换

```cpp
// 字符 → 数字
char ch = '5';
int digit = ch - '0';  // digit = 5

// 数字 → 字符
int digit = 5;
char ch = digit + '0';  // ch = '5'
```

## 六、完整模板代码

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

class BigInt {
public:
    vector<int> digits;  // 倒序存储

    // 从字符串构造
    BigInt(string s = "0") {
        for (int i = s.length() - 1; i >= 0; i--) {
            digits.push_back(s[i] - '0');
        }
        removeLeadingZeros();
    }

    // 去除前导零
    void removeLeadingZeros() {
        while (digits.size() > 1 && digits.back() == 0) {
            digits.pop_back();
        }
    }

    // 转为字符串
    string toString() const {
        string s = "";
        for (int i = digits.size() - 1; i >= 0; i--) {
            s += (char)(digits[i] + '0');
        }
        return s;
    }

    // 高精度加法
    BigInt operator+(const BigInt& other) const {
        BigInt result;
        result.digits.clear();

        int carry = 0;
        int n = max(digits.size(), other.digits.size());

        for (int i = 0; i < n || carry; i++) {
            int sum = carry;
            if (i < digits.size()) sum += digits[i];
            if (i < other.digits.size()) sum += other.digits[i];
            result.digits.push_back(sum % 10);
            carry = sum / 10;
        }

        return result;
    }
};

int main() {
    string a, b;
    cin >> a >> b;

    BigInt num1(a), num2(b);
    BigInt sum = num1 + num2;

    cout << sum.toString() << endl;

    return 0;
}
```

### 例题2：多组数据

**题目**：给定 n 组数据，每组两个大整数，求它们的和。

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

string add(string num1, string num2) {
    vector<int> a, b, c;

    for (int i = num1.length() - 1; i >= 0; i--) {
        a.push_back(num1[i] - '0');
    }
    for (int i = num2.length() - 1; i >= 0; i--) {
        b.push_back(num2[i] - '0');
    }

    int carry = 0;
    for (int i = 0; i < a.size() || i < b.size() || carry; i++) {
        int sum = carry;
        if (i < a.size()) sum += a[i];
        if (i < b.size()) sum += b[i];
        c.push_back(sum % 10);
        carry = sum / 10;
    }

    string result = "";
    for (int i = c.size() - 1; i >= 0; i--) {
        result += (char)(c[i] + '0');
    }
    return result;
}

int main() {
    int n;
    cin >> n;

    while (n--) {
        string a, b;
        cin >> a >> b;
        cout << add(a, b) << endl;
    }

    return 0;
```

## 八、常见错误与调试

### 错误1：忘记处理最后的进位

```cpp
// ❌ 错误
for (int i = 0; i < len; i++) {
    // 加法运算
}

// ✅ 正确
for (int i = 0; i < len || carry; i++) {
    // 加法运算
}
// 或者循环后检查 carry
```

### 错误2：字符转数字时忘记减 '0'

```cpp
// ❌ 错误
a[i] = s[i];  // 存的是 ASCII 码！

// ✅ 正确
a[i] = s[i] - '0';
```

### 错误3：正序存储导致对齐错误

```cpp
// ❌ 错误：正序存储
// 123 → a = [1, 2, 3]
// 45  → b = [4, 5]

// ✅ 正确：倒序存储
// 123 → a = [3, 2, 1]
// 45  → b = [5, 4]
```

## 九、本课小结

### 核心算法

```
高精度加法 = 字符串转数组(倒序) + 逐位相加 + 处理进位 + 转回字符串
```

### 关键公式

```cpp
sum = a[i] + b[i] + carry;
c[i] = sum % 10;
carry = sum / 10;
```

### 代码要点

- ✅ 倒序存储大数
- ✅ 逐位相加，处理进位
- ✅ 不要忘记最后的进位
- ✅ 字符与数字互转
