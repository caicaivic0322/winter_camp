# 📝 第4课 答案与解析：高精度加法

## 一、选择题（每题5分，共30分）

1. **B**
   **解析**：C++ 中 `unsigned long long` 最大约为 $1.8 \times 10^{19}$，无法存储几十位甚至上百位的大整数，因此需要用数组（或字符串）来模拟存储。

2. **B**
   **解析**：高精度运算通常采用**倒序存储**（即个位存放在数组下标 0 的位置），方便对齐和进位处理。`987654` 倒序后为 `4, 5, 6, 7, 8, 9`。

3. **B**
   **解析**：计算结果为 17，当前位保留个位 $17 \% 10 = 7$，进位为 $17 / 10 = 1$。

4. **B**
   **解析**：`100` 位数加 `100` 位数，结果可能是 `100` 位（如 10...0 + 1），也可能是 `101` 位（如 99...9 + 1 产生进位）。最多 101 位。

5. **C**
   **解析**：高精度加法要求两个数位数可以不同，但必须从低位（个位）开始对齐相加。代码通常会在短的数高位补 0 便于计算。结果可能比最长的加数多一位。

6. **B**
   **解析**：`sum % 10` 取当前位的数字，`sum / 10` 取进位值。这是高精度计算的核心步骤。

## 二、判断题（每题5分，共20分）

1. **√**
   **解析**：在加法运算中，每一位（0-9）相加，再加上上一位的进位（0或1），最大为 $9+9+1=19$，进位最大是 $19/10=1$。

2. **√**
   **解析**：倒序存储是为了让个位对齐在下标 0，方便从低位到高位遍历计算。

3. **√**
   **解析**：高精度加法需要遍历两个数的每一位，时间复杂度与位数 $n$ 成正比，即 $O(n)$。

4. **√**
   **解析**：字符运算 `'5' - '0'` 得到整数 5；反之，整数 `5 + '0'` 得到字符 `'5'`。利用的是 ASCII 码的连续性。

## 三、程序完善题（每题25分，共50分）

### 第1题

① `'0'`
② `carry`
③ `%`
④ `/`
⑤ `len++`

**解析**：

- ① 字符转数字：`char - '0'`。
- ② 加法公式：`A[i] + B[i] + carry`（进位）。
- ③ 当前位：和模 10。
- ④ 新进位：和除以 10。
- ⑤ 如果最后还有进位，结果长度加 1，并存入最高位。

### 第2题

① `0`
② `carry` （或 `carry > 0`）
③ `a[i]`
④ `sum / 10`
⑤ `c`

**解析**：

- ① 进位初始为 0。
- ② 循环条件：只要 `a` 没完，或者 `b` 没完，或者还有进位 `carry`，都要继续计算。
- ③ 累加 `a` 的当前位。
- ④ 计算下一轮的进位。
- ⑤ 返回结果 vector `c`。
