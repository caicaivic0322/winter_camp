## 9.1 数组的概念和特性
- 连续内存、随机访问 O(1)
- 下标从 0 开始；越界会导致未定义行为
```cpp
int a[5] = {1, 3, 5, 7, 9};
cout << a[0] << " " << a[4] << endl;
```

---

## 9.2 找最大最小值
```cpp
#include <iostream>
using namespace std;

int main() {
    int n; cin >> n;
    int mx = -1e9, mn = 1e9;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        if (x > mx) mx = x;
        if (x < mn) mn = x;
    }
    cout << mx << " " << mn << endl;
    return 0;
}
```

## 9.3 数组与斐波那契数列
```cpp
int n; cin >> n;
long long f[1000];
f[1] = f[2] = 1;
for (int i = 3; i <= n; i++) f[i] = f[i-1] + f[i-2];
cout << f[n] << endl;
```
