## 二、判断题（每题2分，共10分）

1. **√** (大顶堆堆顶是最大值，小顶堆堆顶是最小值)
2. **×** (堆通常用数组实现最有效，链表难以定位最后一个元素)

## 四、编程题（共30分）

### 第1题：堆排序示例代码

```cpp
void heapSort(int arr[], int n) {
    // 1. 建堆 (从最后一个非叶子节点开始下沉)
    for (int i = n / 2 - 1; i >= 0; i--)
        siftDown(arr, i, n);

    // 2. 排序
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]); // 将堆顶（最大值）交换到末尾
        siftDown(arr, 0, i);   // 重新调整堆
    }
}
```

### 第2题：找第K大示例代码

```cpp
int findKthLargest(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> pq; // 小顶堆
    for (int x : nums) {
        pq.push(x);
        if (pq.size() > k) pq.pop(); // 维护大小为k的小顶堆
    }
    return pq.top(); // 堆顶即为第k大
}
```
