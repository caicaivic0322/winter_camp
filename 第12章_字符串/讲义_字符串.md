## 12.1 C 风格字符串
```cpp
#include <cstdio>
int main() {
    char s[100];
    scanf("%s", s);        // 读取到空白符截止
    printf("%s\n", s);
    return 0;
}
```
- 需要手动处理缓冲区大小与结尾 `\0`

---

## 12.2 `std::string` 常用操作
```cpp
#include <iostream>
using namespace std;
int main() {
    string s; getline(cin, s);
    cout << s.size() << " " << s.substr(0, 5) << endl;
    for (char &ch : s) if (isalpha(ch)) ch = tolower(ch);
    cout << s << endl;
}
```
- `size()`、`substr(pos,len)`、遍历与字符分类函数

---

## 12.3 字符串反转
```cpp
string s; cin >> s;
int l = 0, r = (int)s.size() - 1;
while (l < r) {
    swap(s[l], s[r]);
    l++; r--;
}
cout << s << endl;
```
