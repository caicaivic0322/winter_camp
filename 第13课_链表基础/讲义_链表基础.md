## 二、什么是链表？

### 2.1 数组 vs 链表

| 特性      | 数组          | 链表          |
| --------- | ------------- | ------------- |
| 内存      | 连续          | 分散          |
| 访问      | O(1) 随机访问 | O(n) 顺序访问 |
| 插入/删除 | O(n)          | O(1)          |
| 大小      | 固定          | 动态          |

### 2.2 链表的结构

```
[数据|指针] → [数据|指针] → [数据|指针] → NULL
```

每个节点包含：

- **数据域**：存储数据
- **指针域**：指向下一个节点

struct Node {

## 四、基本操作

### 4.1 创建链表

```cpp
Node* createList() {
    Node* head = new Node(1);
    head->next = new Node(2);
    head->next->next = new Node(3);
    return head;
}
```

### 4.2 遍历链表

```cpp
void printList(Node* head) {
    Node* cur = head;
    while (cur != nullptr) {
        cout << cur->data << " ";
        cur = cur->next;
    }
    cout << endl;
}
```

### 4.3 在头部插入

```cpp
Node* insertAtHead(Node* head, int val) {
    Node* newNode = new Node(val);
    newNode->next = head;
    return newNode;
}
```

### 4.4 在尾部插入

```cpp
void insertAtTail(Node* head, int val) {
    Node* cur = head;
    while (cur->next != nullptr) {
        cur = cur->next;
    }
    cur->next = new Node(val);
}
```

### 4.5 删除节点

```cpp
Node* deleteNode(Node* head, int val) {
    // 删除头节点
    if (head != nullptr && head->data == val) {
        Node* temp = head;
        head = head->next;
        delete temp;
        return head;
    }

    // 删除中间或尾部节点
    Node* cur = head;
    while (cur != nullptr && cur->next != nullptr) {
        if (cur->next->data == val) {
            Node* temp = cur->next;
            cur->next = cur->next->next;
            delete temp;
            return head;
        }
        cur = cur->next;
    }

    return head;
}
```

### 4.6 查找节点

```cpp
Node* search(Node* head, int val) {
    Node* cur = head;
    while (cur != nullptr) {
        if (cur->data == val) return cur;
        cur = cur->next;
    }
    return nullptr;
}
```

## 五、完整示例

```cpp
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
    Node(int val) : data(val), next(nullptr) {}
};

void printList(Node* head) {
    while (head) {
        cout << head->data << " -> ";
        head = head->next;
    }
    cout << "NULL" << endl;
}

int main() {
    // 创建链表：1 -> 2 -> 3
    Node* head = new Node(1);
    head->next = new Node(2);
    head->next->next = new Node(3);

    cout << "原链表：";
    printList(head);

    // 在头部插入 0
    Node* newHead = new Node(0);
    newHead->next = head;
    head = newHead;

    cout << "插入0后：";
    printList(head);

    // 删除节点 2
    Node* cur = head;
    while (cur->next && cur->next->data != 2) {
        cur = cur->next;
    }
    if (cur->next) {
        Node* temp = cur->next;
        cur->next = cur->next->next;
        delete temp;
    }

    cout << "删除2后：";
    printList(head);

    return 0;
}
```

## 六、带头节点的链表

使用**哨兵节点**简化操作：

```cpp
Node* createWithDummy() {
    Node* dummy = new Node(0);  // 哨兵节点
    Node* cur = dummy;

    for (int i = 1; i <= 3; i++) {
        cur->next = new Node(i);
        cur = cur->next;
    }

    return dummy;  // 返回哨兵节点
}
```

## 七、本课小结

### 核心操作

| 操作     | 时间复杂度 |
| -------- | ---------- |
| 头部插入 | O(1)       |

- 注意 nullptr 检查
