# 📘 第16章 文件操作

> 目标：学会用 C++ 读写文本文件，完成批量数据处理

---

## 16.1 基本打开与关闭
```cpp
#include <fstream>
using namespace std;

int main() {
    ifstream fin("input.txt");
    ofstream fout("output.txt");
    if (!fin.is_open() || !fout.is_open()) return 0;
    // ...
    fin.close(); fout.close();
}
```

---

## 16.2 文件读写
```cpp
int x, y;
while (fin >> x >> y) {  // 按空白分隔读取直到 EOF
    fout << (x + y) << "\n";
}
```

---

## 16.3 行读取与字符串处理
```cpp
#include <string>
string line;
while (getline(fin, line)) {
    // 处理整行
    fout << line << "\n";
}
```
