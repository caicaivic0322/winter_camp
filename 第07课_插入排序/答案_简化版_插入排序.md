# 📝 第7课 答案与解析：插入排序

## 一、选择题（每题5分，共30分）

1. **B**
   **解析**：插入排序模拟了我们在打牌时整理手牌的过程：摸一张新牌，从后往前看，找到合适的位置插入。

2. **B**
   **解析**：最好的情况是数组已经有序，此时只需要遍历一遍，不用移动元素，时间复杂度 $O(n)$。

3. **A**
   **解析**：
   - 初始：`[3, 1, 4]` (设第1个 3 已有序)
   - 第一轮（插入 1）：1 比 3 小，3 后移，1 插到头 -> `[1, 3, 4]`。

4. **B**
   **解析**：插入排序在元素相等时不移动相对位置（判断条件通常是 $>key$ 才移动），所以是稳定排序。

5. **A**
   **解析**：原地排序，只需要常数级额外空间用于交换/暂存（`key`），空间复杂度 $O(1)$。

6. **B**
   **解析**：当数据规模小或基本有序时，插入排序效率很高，常作为快速排序等复杂排序的子过程（当分治到小规模时）。

## 二、判断题（每题5分，共20分）

1. **√**
   **解析**：对于基本有序数组，插入排序几乎不需要移动元素，接近 $O(n)$。

2. **×**
   **解析**：是原地排序，除了几个变量外不需要额外空间。

3. **√**
   **解析**：稳定性的定义。

4. **×**
   **解析**：已经有序时是 $O(n)$。

## 三、程序完善题（每题25分，共50分）

### 第1题

① `arr[i]`
② `>`
③ `j`
④ `j+1`

**解析**：

- ① 把当前待排序元素暂存到 `key`。
- ② 如果前面的元素 `arr[j]` 比 `key` 大，则需要后移。
- ③ 后移操作：`arr[j+1] = arr[j]`。
- ④ 循环结束后，`j+1` 就是 `key` 应该插入的位置。

### 第2题

① `<`
② `key`

**解析**：

- ① 降序排列，需要把比 `key` **小** 的元素后移，所以条件改为 `arr[j] < key`。
- ② 找到位置后赋值 `key`（填空处虽然只有变量名，但实际上是赋值语句右边）。
