## 二、插入排序的直观理解

### 2.1 打牌的过程

想象你在整理手中的扑克牌：

1. 拿起第一张牌，放在手上
2. 拿起第二张牌，插入到合适的位置
3. 拿起第三张牌，找到位置插入
4. ...依此类推

**这就是插入排序的核心思想！**

### 2.2 动态过程演示

对数组 `[5, 2, 4, 6, 1]` 进行插入排序：

```
初始：     [5] | 2, 4, 6, 1
第1轮：    [2, 5] | 4, 6, 1
第2轮：    [2, 4, 5] | 6, 1
第3轮：    [2, 4, 5, 6] | 1
第4轮：    [1, 2, 4, 5, 6]
```

## 三、代码实现

```cpp
#include <iostream>
using namespace std;

void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];     // 取出待插入的元素
        int j = i - 1;

        // 找到插入位置，同时后移元素
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;  // 插入
    }
}

int main() {
    int arr[] = {5, 2, 4, 6, 1};
    int n = 5;

    insertionSort(arr, n);

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    return 0;
}
```

## 四、时间复杂度

| 情况           | 时间复杂度 |
| -------------- | ---------- |
| 最好（已有序） | O(n)       |
| 最坏（逆序）   | O(n²)      |
| 平均           | O(n²)      |

**空间复杂度**：O(1)
**稳定性**：稳定

## 五、特点

- ✅ 简单直观，易于理解
- ✅ 对基本有序的数组效率高
- ✅ 稳定排序
- ⚠️ 对于大规模数据效率较低
