# 📘 第10章 嵌套循环

> 目标：掌握双重及多重循环的控制方式，解决网格类与枚举类问题

---

## 10.1 基本概念
```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        // 处理 (i, j)
    }
}
```
- 外层控制行，内层控制列；时间复杂度约为 O(nm)

---

## 10.2 经典例题
1) 打印 n×m 的矩形（由 `*` 组成）
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) cout << '*';
    cout << '\n';
}
```
2) 枚举三位数的“水仙花数”
```cpp
for (int x = 100; x <= 999; x++) {
    int a = x/100, b = (x/10)%10, c = x%10;
    if (a*a*a + b*b*b + c*c*c == x) cout << x << "\n";
}
```
