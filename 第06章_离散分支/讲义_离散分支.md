# 📘 第6章 离散分支（switch）

> 目标：熟练使用 switch 分支，理解 case、break、default 的行为

---

## 6.1 switch分支结构
```cpp
int x; cin >> x;
switch (x) {
case 0: cout << "zero\n"; break;
case 1: cout << "one\n";  break;
case 2: 
case 3: cout << "two or three\n"; break; // 合并分支
default: cout << "others\n";
}
```
- `switch` 只能用于整型/字符/枚举等可离散判定的类型
- 若缺少 `break` 将继续“贯穿”到下一个 case

---

## 6.2 default语句
- 当所有 `case` 都不匹配时执行 `default`
- 可省略，但建议保留以处理异常输入

---

## 6.3 break语句的使用
```cpp
char op; int a, b; 
cin >> op >> a >> b;
switch (op) {
case '+': cout << a + b << endl; break;
case '-': cout << a - b << endl; break;
case '*': cout << a * b << endl; break;
case '/': cout << (b ? a / b : 0) << endl; break;
default: cout << "invalid\n";
}
```
