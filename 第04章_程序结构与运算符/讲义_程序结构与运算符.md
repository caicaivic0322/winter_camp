# 📘 第4章 程序结构与运算符

> 目标：掌握常见运算符与表达式求值规则，能编写基本的分支结构

---

## 4.1 三目运算符
```cpp
int a = 5, b = 8;
int m = (a > b) ? a : b;  // 取较大值
```
- 形式：`条件 ? 值1 : 值2`

---

## 4.2 关系与逻辑运算符
- 关系：`> < >= <= == !=`
- 逻辑：`&&` 与，`||` 或，`!` 非（存在短路行为）
```cpp
int x = 3, y = 7;
bool ok = (x < y) && (y < 10); // true
```

---

## 4.3 表达式与优先级
- 算术：`+ - * / %`
- 自增自减：`++i`/`i++`（前置先加后用；后置先用后加）
- 赋值：`= += -= *= /= %=`
```cpp
int i = 0;
int a = i++; // a=0, i=1
int b = ++i; // i=2, b=2
```

---

## 4.4 if-else结构
```cpp
#include <iostream>
using namespace std;

int main() {
    int score; 
    cin >> score;
    if (score >= 90)      cout << "A\n";
    else if (score >= 80) cout << "B\n";
    else if (score >= 60) cout << "C\n";
    else                  cout << "D\n";
    return 0;
}
```
