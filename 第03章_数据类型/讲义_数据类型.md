# 📘 第3章 数据类型

> 目标：理解位与字节、各基础数据类型的范围与特征，学会选择合适的数据类型

---

## 3.1 计算机基础知识
- 计算机以二进制存储数据（0/1）
- 数值范围与所占位数相关，位数越多可表示的范围越大

---

## 3.2 位和字节的概念
- 位（bit）：二进制的一位，取值 0 或 1
- 字节（byte）：8 个 bit = 1 byte
- 常见类型的典型大小（以主流编译器为例）：`char` 1B、`int` 4B、`long long` 8B、`double` 8B

---

## 3.3 C++的基本数据类型
```cpp
#include <iostream>
using namespace std;

int main() {
    char c = 'a';          // 字符
    int x = 2147483647;    // 约 2.1e9
    long long y = 9000000000000000000LL; // 9e18
    float f = 3.14f;
    double d = 3.1415926535;
    bool ok = true;
    cout << c << " " << x << " " << y << " " << f << " " << d << " " << ok << endl;
    return 0;
}
```
- 注意：整型溢出会导致未定义或环绕（实现相关），应选择足够范围的类型

---

## 3.4 数据类型的选择与应用
- 计数与下标：`int` 足够时用 `int`，数据上限超 2e9 时用 `long long`
- 金额与高精度累计：`long long` 或者以“分”为单位存储
- 科学计算/小数：`double`（注意误差）；严格小数精度可考虑用整数表示（放大 100/1000）
- 字符串：`std::string`，字符用 `char`

---

## 示例：溢出与类型选择
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 2000000000;      // 2e9
    int b = 2000000000;      // 再加 2e9 可能溢出
    long long c = 2000000000LL + 2000000000LL; // 正确
    cout << "int 加法可能溢出: " << (a + b) << endl;
    cout << "long long 正确结果: " << c << endl;
    return 0;
}
```
