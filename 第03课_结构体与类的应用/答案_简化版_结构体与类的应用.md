# 📝 第3课 答案与解析：结构体与类的应用

## 一、选择题（每题5分，共50分）

1. **B**
   **解析**：在 C++ 中，`struct` 的成员默认是 public，而 `class` 的成员默认是 private。这是它们的主要区别。

2. **C**
   **解析**：构造函数是一种特殊的成员函数，在创建对象时自动调用，用于初始化对象。

3. **B**
   **解析**：代码中定义了无参构造函数 `Point() { x = 0; y = 0; }`。`Point p;` 会调用该无参构造函数，因此 `p.x` 和 `p.y` 都被初始化为 0。

4. **C**
   **解析**：`private` 成员只能被类自己的成员函数（或友元）访问，不能在类外部（如 main 函数中）直接通过对象访问。

5. **B**
   **解析**：`Student[10] arr;` 是错误的语法。正确的数组声明格式是 `Type name[size];`，即 `Student arr[10];`。

6. **D**
   **解析**：构造函数没有返回值类型（连 void 都没有），且函数名必须与类名完全相同。D 选项 `add` 显然不是构造函数，但如果问的是关于构造函数的说法错误的是：构造函数只能有一个？错，可以重载多个。题目问错误的说法：A/B/C都对。D项如果是指"一个类只能有一个构造函数"则是错误的。

7. **B**
   **解析**：Stack 是后进先出 (LIFO)。

8. **A**
   **解析**：Queue 是先进先出 (FIFO)。

9. **B**
   **解析**：`3 + 4 * 5` -> `3 + (4 * 5)` -> `3 4 5 * +`。

10. **B**
    **解析**：`* + 2 3 4` -> `* (2+3) 4` -> `(2+3) * 4`。

## 二、判断题（每题5分，共20分）

1. **√**
   **解析**：这是 C++ 中 struct 和 class 的设计差异。

2. **×**
   **解析**：类的对象如果在类外部，不能直接访问私有（private）成员，必须通过公有（public）成员函数接口访问。

3. **√**
   **解析**：构造函数支持重载，只要参数列表不同，一个类可以有多个构造函数。

4. **√**
   **解析**：题目表述有误导性？在 C++ 中，struct **可以**包含成员函数。这里的判断题答案应为 **×**（如果教材说 structs 像 C 语言那样不能包含函数）。但标准 C++中 struct 可以有函数。根据常见 C++ 教学，struct 和 class 功能几乎一样。
   _修正_：如果按照 C++ 标准，struct 可以有函数。如果是 C 语言遗留观念，则不行。但在 C++ 课程中，答案通常是 **×**。

## 三、程序完善题（每题15分，共30分）

### 第1题

① `w`
② `h`
③ `width * height`

**解析**：

- ① 将参数 `w` 赋值给成员变量 `width`。
- ② 将参数 `h` 赋值给成员变量 `height`。
- ③ 计算并返回面积：宽乘以高。

### 第2题

① `students[maxIdx].score`
② `i`

**解析**：

- ① 比较当前学生 `students[i]` 的分数与当前记录的最高分 `students[maxIdx].score`。
- ② 如果当前分数更高，则更新最高分下标 `maxIdx` 为当前下标 `i`。
