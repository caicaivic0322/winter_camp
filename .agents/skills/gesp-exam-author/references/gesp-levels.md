# GESP Levels

This file maps likely knowledge scope for paper design. Use it as a practical teaching guide, not as a legal exam syllabus.

## Python

### GESP 1

- 基本输入输出
- 变量与数据类型初步
- 字符串、整数、浮点数基础
- 算术运算、比较运算
- 简单 `if`
- 简单 `for` / `range`

Avoid:

- Deep nesting
- Functions as a core topic
- Complex list/string tricks

### GESP 2

- 分支结构完整使用
- `for` / `while`
- 累加、计数、求和
- 整除、取模、幂运算
- 链式比较与逻辑运算

### GESP 3

- 列表基础
- 字符串常见操作
- 简单函数
- 基础遍历与统计
- 条件与循环综合

### GESP 4

- 列表/字符串综合
- 函数参数与返回值
- 枚举、简单模拟
- 基础二维数据处理

### GESP 5

- 更完整的模块化思维
- 多层条件与循环综合
- 更复杂的模拟
- 简单算法设计意识

### GESP 6

- 偏综合应用
- 更稳定的算法表达
- 函数化组织
- 需要更强的边界条件意识

## C++

### GESP 1

- `cin` / `cout`
- 变量与基本类型
- 算术表达式
- 简单 `if`

### GESP 2

- `if-else`
- `switch`
- `for` / `while`
- 整除取模
- 简单累加统计

### GESP 3

- 一维数组基础
- 字符/字符串基础
- 简单函数
- 多组输入与遍历

### GESP 4

- 数组综合
- 字符串处理
- 函数综合
- 枚举与模拟

### GESP 5

- 结构化问题拆解
- 更复杂循环与条件
- 基础算法思维
- 常见容器入门视情况使用

### GESP 6

- 综合题能力更强
- 更重视边界、效率与逻辑完整性
- 仍应保持教学型、可判定的题面

## Difficulty calibration rules

- GESP 1-2: emphasize correctness of basics
- GESP 3-4: emphasize understanding plus small combinations
- GESP 5-6: emphasize multi-step reasoning without becoming olympiad-only

## Universal quality rules

- One best answer only
- Stems should match the target grade's vocabulary
- Code should be executable or clearly pseudocode-like within the chosen language
- Distractors should reflect real beginner mistakes
