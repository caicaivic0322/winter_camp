# Exam Structure

Use this as the default composition when the user does not specify counts.

## Default full paper

- 单选题: 20
- 判断题: 10
- 程序完善题: 8

This matches the working paper shape already used in the repository.

## Recommended scoring

- 单选题: 2 分 / 题
- 判断题: 2 分 / 题
- 程序完善题: 5 分 / 题

## Section order

Always keep this order:

1. `## 一、单选题`
2. `## 二、判断题`
3. `## 三、程序完善题`
4. `## 参考答案汇总`

## Paper design guidance

### GESP 1-2

- More syntax, variables, input/output, basic branching and loops
- Fewer nested logic traps
- Code-completion should be short and single-purpose

### GESP 3-4

- Add more expression reasoning, loop control, simple functions, lists/arrays, strings, simulation
- Distractors can test precedence and common misconceptions

### GESP 5-6

- Allow more structured reasoning, composite conditions, moderate algorithmic thinking, functions, containers/basic data structures depending on language track
- Still prefer deterministic school-style questions over contest riddles unless requested

## If the user asks for a small quiz

Recommended compact set:

- 单选题: 5
- 判断题: 3
- 程序完善题: 2
