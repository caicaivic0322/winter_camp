# 📝 第17课 答案与解析：unordered_map 详解

## 一、选择题（每题5分，共30分）

1. **C**
   **解析**：unordered_map 底层实现是哈希表，通过哈希函数实现 O(1) 查找。

2. **B**
   **解析**：unordered_map 查找更快（O(1)），但元素无序；map 有序（O(log n)）。

3. **B**
   **解析**：检查键是否存在可以用 `find()`（返回迭代器）或 `count()`（返回0或1）。

4. **C**
   **解析**：下标访问不存在的键会插入一个默认值（如 int 为 0）并返回引用。

5. **B**
   **解析**：范围 for 循环是遍历 unordered_map 最常用的方式。

6. **B**
   **解析**：map 底层是红黑树，会按 key 升序遍历；unordered_map 无序。

## 二、判断题（每题5分，共20分）

1. **√**
   **解析**：unordered_map 的插入、查找、删除平均时间复杂度都是 O(1)。

2. **×**
   **解析**：`erase(key)` 返回的是删除的元素个数（0或1），不是被删除的值。

3. **√**
   **解析**：`find(key)` 返回指向键值对的迭代器，如果未找到返回 `end()`。

4. **√**
   **解析**：负载因子过大时冲突增多，查找性能从 O(1) 退化到 O(n)。

## 三、填空题（每题5分，共25分）

1. **`<unordered_map>`**
   **解析**：使用 unordered_map 需要包含对应头文件。

2. **`cnt[c]++`**
   **解析**：统计每个字符出现次数。

3. **`clear()`**
   **解析**：清空哈希表所有元素。

4. **`pair<const Key, Value>`（或键值对）**
   **解析**：unordered_map 存储的是键值对。

5. **`find()` 或 `count()`**
   **解析**：插入前检查键是否存在。

## 四、程序完善题（每题25分，共25分）

### 两数之和

① `unordered_map<int, int> mp`
   **解析**：声明哈希表存储 值->索引 的映射。

② `count`
   **解析**：检查互补的数是否存在。

③ `mp[nums[i]]`
   **解析**：存入当前数和对应的索引。
