## 5.1 逻辑运算符
- 与：`&&`；或：`||`；非：`!`（存在短路，前半已能确定结果时不再计算后半）
```cpp
bool a = true, b = false;
cout << (a && b) << " " << (a || b) << " " << (!a) << endl;
```

## 5.2 分支嵌套
```cpp
int t; cin >> t;
if (t >= 0) {
    if (t <= 35) cout << "normal\n";
    else cout << "hot\n";
} else {
    cout << "cold\n";
}
```

## 5.3 条件分支的综合运用
问题：读取一个日期（年、月、日），判断其是否合法。
```cpp
#include <iostream>
using namespace std;

bool isLeap(int y) { return (y % 400 == 0) || (y % 4 == 0 && y % 100 != 0); }

int main() {
    int y, m, d; cin >> y >> m >> d;
    int md[] = {0,31,28,31,30,31,30,31,31,30,31,30,31};
    if (m == 2 && isLeap(y)) md[2] = 29;
    if (y >= 1 && m >= 1 && m <= 12 && d >= 1 && d <= md[m]) cout << "valid\n";
    else cout << "invalid\n";
    return 0;
}
```
