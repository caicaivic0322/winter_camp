## 二、堆的概念

### 2.1 什么是堆？

**堆**是一种特殊的完全二叉树，满足：

- **大顶堆**：每个节点的值 ≥ 子节点的值
- **小顶堆**：每个节点的值 ≤ 子节点的值

### 2.2 堆的性质

```
大顶堆示例：
        9
       / \
      7   8
     / \   \
    5   6   3

数组表示：[9, 7, 8, 5, 6, 3]
下标：     0  1  2  3  4  5
```

**关键关系**（从 0 开始编号）：

- 父节点：`(i - 1) / 2`
- 左子节点：`2 * i + 1`
- 右子节点：`2 * i + 2`

## 三、堆的基本操作

### 3.1 上浮（插入新元素）

```cpp
void siftUp(int arr[], int i) {
    while (i > 0 && arr[i] > arr[(i - 1) / 2]) {
        swap(arr[i], arr[(i - 1) / 2]);
        i = (i - 1) / 2;
    }
}
```

### 3.2 下沉（删除堆顶）

```cpp
void siftDown(int arr[], int i, int n) {
    while (2 * i + 1 < n) {
        int j = 2 * i + 1;  // 左子节点
        if (j + 1 < n && arr[j + 1] > arr[j]) j++;  // 选更大的子节点
        if (arr[i] >= arr[j]) break;
        swap(arr[i], arr[j]);
        i = j;
    }
}
```

### 3.3 建堆

```cpp
void buildHeap(int arr[], int n) {
    // 从最后一个非叶节点开始下沉
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, i, n);
    }
}
```

## 四、堆排序

### 4.1 原理

1. 建立大顶堆
2. 将堆顶（最大值）与末尾交换
3. 堆大小减 1，对堆顶进行下沉
4. 重复步骤 2-3

### 4.2 代码实现

```cpp
#include <iostream>
using namespace std;

void siftDown(int arr[], int i, int n) {
    while (2 * i + 1 < n) {
        int j = 2 * i + 1;
        if (j + 1 < n && arr[j + 1] > arr[j]) j++;
        if (arr[i] >= arr[j]) break;
        swap(arr[i], arr[j]);
        i = j;
    }
}

void heapSort(int arr[], int n) {
    // 建堆
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, i, n);
    }

    // 排序
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]);  // 堆顶与末尾交换
        siftDown(arr, 0, i);   // 下沉
    }
}

int main() {
    int arr[] = {5, 3, 8, 4, 2, 7, 1, 6};
    int n = 8;
    heapSort(arr, n);
    for (int i = 0; i < n; i++) cout << arr[i] << " ";
    return 0;
}
```

## 五、priority_queue 的使用

### 5.1 基本用法

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    // 大顶堆（默认）
    priority_queue<int> maxHeap;
    maxHeap.push(3);
    maxHeap.push(1);
    maxHeap.push(4);
    cout << maxHeap.top() << endl;  // 4
    maxHeap.pop();
    cout << maxHeap.top() << endl;  // 3

    // 小顶堆
    priority_queue<int, vector<int>, greater<int>> minHeap;
    minHeap.push(3);
    minHeap.push(1);
    minHeap.push(4);
    cout << minHeap.top() << endl;  // 1

    return 0;
}
```

### 5.2 常用操作

| 操作   | 方法      | 时间复杂度 |
| ------ | --------- | ---------- |
| 入堆   | `push(x)` | O(log n)   |
| 取堆顶 | `top()`   | O(1)       |
| 出堆   | `pop()`   | O(log n)   |
| 判空   | `empty()` | O(1)       |
| 大小   | `size()`  | O(1)       |

## 六、应用：Top K 问题

### 找最大的 K 个数

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int arr[] = {3, 2, 1, 5, 6, 4};
    int n = 6, k = 2;

    // 使用小顶堆，维护 k 个最大的数
    priority_queue<int, vector<int>, greater<int>> minHeap;

    for (int i = 0; i < n; i++) {
        minHeap.push(arr[i]);
        if (minHeap.size() > k) minHeap.pop();
    }

    // 堆中就是最大的 k 个数
    while (!minHeap.empty()) {
        cout << minHeap.top() << " ";
        minHeap.pop();
    }
    // 输出: 5 6

    return 0;
}
```

## 八、本课小结

### 核心知识点

1. 堆是完全二叉树，用数组存储
2. 父子关系通过下标计算
3. `priority_queue` 是 STL 提供的堆实现
4. 堆排序时间复杂度 O(n log n)，空间 O(1)

### 实用技巧

- 大顶堆：`priority_queue<int>`
- 小顶堆：`priority_queue<int, vector<int>, greater<int>>`
- Top K 问题用堆高效解决
