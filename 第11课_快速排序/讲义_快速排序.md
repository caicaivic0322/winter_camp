## 二、快速排序的核心思想

### 2.1 一句话概括

**选一个基准，把小的放左边，大的放右边，然后递归处理左右两部分。**

### 2.2 与归并排序的对比

| 特点 | 归并排序       | 快速排序         |
| ---- | -------------- | ---------------- |
| 分解 | 简单（取中间） | 复杂（分区）     |
| 合并 | 复杂           | 简单（无需操作） |
| 思路 | 先分后合       | 先处理后递归     |

### 2.3 直观理解

想象整理一堆高矮不同的学生：

1. 选一个学生作为"标准"
2. 比他矮的站左边，比他高的站右边
3. 对左边和右边分别重复这个过程

## 三、分区操作（Partition）

### 3.1 分区的目标

选择一个**基准值（pivot）**，将数组分成两部分：

- 左边的元素都 ≤ pivot
- 右边的元素都 ≥ pivot

### 3.2 分区过程示例

对 `[5, 3, 8, 4, 2, 7, 1, 6]` 以 5 为基准进行分区：

```
初始:  [5, 3, 8, 4, 2, 7, 1, 6]
       ↑                     ↑
       i                     j

步骤1: j 找到 1（比5小），i 找到 8（比5大），交换
       [5, 3, 1, 4, 2, 7, 8, 6]
              ↑     ↑
              i     j

步骤2: j 找到 2，i 找到 7（不对，应该继续找...）
       继续处理...

最终:  [1, 3, 2, 4, 5, 7, 8, 6]
                   ↑
                 pivot 在正确位置
```

## 四、代码实现

### 4.1 Lomuto 分区方案（简单版）

```cpp
#include <iostream>
using namespace std;

// 分区函数：返回基准值的最终位置
int partition(int arr[], int low, int high) {
    int pivot = arr[high];  // 选择最后一个元素作为基准
    int i = low - 1;        // i 指向小于 pivot 区域的末尾

    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }

    swap(arr[i + 1], arr[high]);  // 把 pivot 放到正确位置
    return i + 1;
}

void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);   // 排序左半部分
        quickSort(arr, pi + 1, high);  // 排序右半部分
    }
}

int main() {
    int arr[] = {5, 3, 8, 4, 2, 7, 1, 6};
    int n = 8;

    quickSort(arr, 0, n - 1);

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}
```

### 4.2 Hoare 分区方案（经典版）

```cpp
#include <iostream>
using namespace std;

int partition(int arr[], int low, int high) {
    int pivot = arr[(low + high) / 2];  // 选择中间元素作为基准
    int i = low - 1;
    int j = high + 1;

    while (true) {
        do { i++; } while (arr[i] < pivot);
        do { j--; } while (arr[j] > pivot);

        if (i >= j) return j;

        swap(arr[i], arr[j]);
    }
}

void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi);
        quickSort(arr, pi + 1, high);
    }
}

int main() {
    int arr[] = {5, 3, 8, 4, 2, 7, 1, 6};
    int n = 8;

    quickSort(arr, 0, n - 1);

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}
```

## 五、详细步骤追踪

对 `[5, 2, 4, 6, 1, 3]` 进行快速排序（Lomuto 方案）：

```
初始数组: [5, 2, 4, 6, 1, 3]

第一次分区 (pivot = 3):
  j=0: 5>3, 不动
  j=1: 2<=3, i=0, 交换 arr[0] 和 arr[1] → [2, 5, 4, 6, 1, 3]
  j=2: 4>3, 不动
  j=3: 6>3, 不动
  j=4: 1<=3, i=1, 交换 arr[1] 和 arr[4] → [2, 1, 4, 6, 5, 3]
  最后: 交换 arr[2] 和 arr[5] → [2, 1, 3, 6, 5, 4]
  pivot=3 的位置是 2

对左边 [2, 1] 分区 (pivot = 1):
  结果: [1, 2]

对右边 [6, 5, 4] 分区 (pivot = 4):
  结果: [4, 5, 6]

最终: [1, 2, 3, 4, 5, 6]
```

## 六、时间复杂度分析

### 6.1 最好情况

每次分区都恰好平分：

```
T(n) = 2T(n/2) + O(n) = O(n log n)
```

### 6.2 最坏情况

每次分区极度不平衡（数组已有序时）：

```
T(n) = T(n-1) + O(n) = O(n²)
```

### 6.3 平均情况

```
O(n log n)
```

### 6.4 如何避免最坏情况

1. **随机选择基准**
2. **三数取中法**：取 low、mid、high 三个位置的中值

```cpp
// 三数取中
int mid = (low + high) / 2;
if (arr[low] > arr[mid]) swap(arr[low], arr[mid]);
if (arr[low] > arr[high]) swap(arr[low], arr[high]);
if (arr[mid] > arr[high]) swap(arr[mid], arr[high]);
int pivot = arr[mid];
```

## 七、快速排序的特点

### 7.1 优点

✅ 平均情况 O(n log n)
✅ 原地排序，空间复杂度 O(log n)（递归栈）
✅ 实际运行速度快（常数因子小）

### 7.2 缺点

❌ 最坏情况 O(n²)
❌ 不稳定排序
❌ 对几乎有序的数组可能表现差

### 7.3 与其他算法对比

| 算法     | 平均时间   | 最坏时间   | 空间     | 稳定 |
| -------- | ---------- | ---------- | -------- | ---- |
| 快速排序 | O(n log n) | O(n²)      | O(log n) | ×    |
| 归并排序 | O(n log n) | O(n log n) | O(n)     | ✓    |
| 堆排序   | O(n log n) | O(n log n) | O(1)     | ×    |

## 八、使用 STL 的 sort

在实际竞赛中，通常直接使用 `sort`：

```cpp
#include <iostream>

int main() {

    sort(arr, arr + n, greater<int>());

```

## 九、例题精讲

### 例题1：第 K 小的数

```cpp
#include <iostream>
using namespace std;

int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return i + 1;
}

// 快速选择：找第 k 小的数（O(n) 平均时间）
int quickSelect(int arr[], int low, int high, int k) {
    if (low == high) return arr[low];

    int pi = partition(arr, low, high);

    if (pi == k - 1) {
        return arr[pi];
    } else if (pi > k - 1) {
        return quickSelect(arr, low, pi - 1, k);
    } else {
        return quickSelect(arr, pi + 1, high, k);
    }
}

int main() {
    int arr[] = {3, 2, 1, 5, 6, 4};
    int n = 6;
    int k = 2;  // 找第 2 小的数

    cout << "第 " << k << " 小的数是: ";
    cout << quickSelect(arr, 0, n - 1, k) << endl;
    // 输出: 2

    return 0;
}
```
