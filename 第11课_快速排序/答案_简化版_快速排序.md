# 📝 第11课 答案与解析：快速排序

## 一、选择题（每题5分，共30分）

1. **B**
   **解析**：快速排序的核心是分区（Partition）操作，选定一个基准，将小于基准的放左边，大于基准的放右边。

2. **B**
   **解析**：平均情况下，每次划分都比较均匀，递归深度 $\log n$，每层 $O(n)$，总复杂度 $O(n \log n)$。

3. **D**
   **解析**：标准快速排序（选第一个或最后一个为基准）在数组完全有序（正序或逆序）或元素全部相同时，会退化为 $O(n^2)$。

4. **B**
   **解析**：分区过程中涉及长距离交换，可能改变相等元素的相对位置，是不稳定的。

5. **B**
   **解析**：递归调用栈的空间，最好/平均 $O(\log n)$，最坏 $O(n)$。

6. **C**
   **解析**：
   - 数组 `[3, 1, 4, 1, 5]`，基准是 `5`。
   - `3 <= 5`，`1 <= 5`，`4 <= 5`，`1 <= 5`，所有元素都比 5 小。
   - 5 最终会留在原位（下标 4），即最后一位。

## 二、判断题（每题5分，共20分）

1. **√**
   **解析**：Partition 完成后，基准元素归位，左边都比它小，右边都比它大，它的位置就是最终排序后的位置。

2. **×**
   **解析**：最坏情况 $O(n^2)$，插入排序在最坏情况也是 $O(n^2)$。但一般认为快排常数小，平均快。如果是指“最坏情况比插入排序的最好情况（$O(n)$）慢”，那是对的。但泛泛比较通常指平均。不过题目说“最坏情况比插入排序慢”，插入排序最坏也是 $n^2$，两者同级。但插入排序在“几乎有序”时是 $O(n)$，快排最坏（有序）是 $O(n^2)$，这时确实快排慢。

3. **√**
   **解析**：可以用栈来模拟递归调用，实现非递归的快速排序。

4. **×**
   **解析**：三数取中或选中位数只能*降低*最坏情况出现的概率，不能*完全避免*（针对精心构造的“杀手”数据，依然可能退化）。

## 三、程序完善题（每题25分，共50分）

### 第1题

① `high`
② `high`
③ `j`
④ `i + 1`

**解析**：

- ① 选择最后一个元素 `arr[high]` 作为基准。
- ② 遍历范围是 `low` 到 `high-1`。
- ③ 发现小于等于基准的数，与 `arr[i+1]` 交换（代码中 `i` 先自增了，所以是 `swap(arr[i], arr[j])`）。
- ④ 遍历结束后，将基准元素放到 `i+1` 的位置，完成分区。

### 第2题

① `low`
② `high`
③ `pi - 1`
④ `pi + 1`

**解析**：

- ① 递归终止条件：`low >= high`。
- ② 递归调用条件。
- ③ 对基准左边的子数组 `[low, pi-1]` 进行排序。
- ④ 对基准右边的子数组 `[pi+1, high]` 进行排序。
