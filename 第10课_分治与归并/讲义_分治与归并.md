## 二、分治思想

### 2.1 核心概念

分治法将一个难以直接解决的大问题，分割成一些规模较小的相同问题，以便各个击破，分而治之。

**三个步骤**：
1. **分解（Divide）**：将原问题分解为若干个规模较小，相互独立，与原问题形式相同的子问题。
2. **解决（Conquer）**：若子问题规模较小而容易被解决则直接解，否则递归地解各个子问题。
3. **合并（Combine）**：将各个子问题的解合并为原问题的解。

## 三、二分查找 (Binary Search)

### 3.1 算法原理

在**有序数组**中查找特定元素。每次比较中间元素，将搜索范围缩小一半。

### 3.2 代码实现

```cpp
// 查找 target 是否存在
bool binarySearch(int arr[], int n, int target) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return true;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return false;
}
```

### 3.3 STL 中的二分

- `binary_search`: 检查是否存在
- `lower_bound`: 找第一个 **≥** target 的位置
- `upper_bound`: 找第一个 **>** target 的位置

```cpp
int arr[] = {1, 2, 4, 4, 6};
int pos1 = lower_bound(arr, arr+5, 4) - arr; // 返回 2 (第一个4的下标)
int pos2 = upper_bound(arr, arr+5, 4) - arr; // 返回 4 (6的下标)
```

## 四、归并排序 (Merge Sort)

### 4.1 算法流程

1. **分解**：将数组从中点分开，递归排序左右两半。
2. **合并**：将两个有序的子数组合并成一个有序数组。

### 4.2 代码实现

```cpp
int temp[100005]; // 辅助数组

void merge(int arr[], int l, int mid, int r) {
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (arr[i] <= arr[j]) temp[k++] = arr[i++];
        else temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= r) temp[k++] = arr[j++];
    for (int i = l; i <= r; i++) arr[i] = temp[i];
}

void mergeSort(int arr[], int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(arr, l, mid);
    mergeSort(arr, mid + 1, r);
    merge(arr, l, mid, r);
}
```

### 4.3 复杂度

- 时间复杂度：$O(n \log n)$
- 空间复杂度：$O(n)$（需要辅助数组）
- 稳定性：**稳定**

## 五、进阶应用：逆序对

### 5.1 什么是逆序对？

在数组中，如果 `i < j` 且 `arr[i] > arr[j]`，则 `(i, j)` 就是一个逆序对。
例如：`[2, 4, 3, 5, 1]` 的逆序对有 `(2,1), (4,3), (4,1), (3,1), (5,1)` 共 5 个。

### 5.2 利用归并排序统计

在 `merge` 过程中，当右边元素 `arr[j]` 放入 `temp` 时，说明左边剩下的所有元素（从 `i` 到 `mid`）都比 `arr[j]` 大。

```cpp
long long cnt = 0; // 逆序对可能很多，用 long long

void merge(int arr[], int l, int mid, int r) {
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
            cnt += (mid - i + 1); // 核心：累加逆序对
        }
    }
    // ...其余部分同普通归并
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= r) temp[k++] = arr[j++];
    for (int i = l; i <= r; i++) arr[i] = temp[i];
}
```

## 六、随堂练习

### 练习 1：查找第一个出现的位置

**题目**：给定一个升序数组（可能包含重复元素）和一个目标值 target，请找出 target 第一次出现的下标。如果不存在，输出 -1。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int arr[] = {1, 2, 4, 4, 4, 6};
    int n = 6;
    int target = 4;
    
    // 使用 lower_bound
    int pos = lower_bound(arr, arr + n, target) - arr;
    
    if (pos < n && arr[pos] == target) {
        cout << "First occurrence: " << pos << endl;
    } else {
        cout << "-1" << endl;
    }
    return 0;
}
```
