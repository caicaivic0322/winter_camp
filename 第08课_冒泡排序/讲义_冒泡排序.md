## 二、冒泡排序的直观理解

### 2.1 名字的由来

想象水中的气泡：**大气泡向上冒，小气泡留在下面**。

在排序中：每一轮比较，**最大的元素会像气泡一样"冒"到数组末尾**。

### 2.2 动态过程演示

对数组 `[5, 3, 8, 4, 2]` 进行冒泡排序：

```
第一轮（将最大值 8 冒到末尾）:
[5, 3, 8, 4, 2]  比较 5,3 → 交换 → [3, 5, 8, 4, 2]
[3, 5, 8, 4, 2]  比较 5,8 → 不换 → [3, 5, 8, 4, 2]
[3, 5, 8, 4, 2]  比较 8,4 → 交换 → [3, 5, 4, 8, 2]
[3, 5, 4, 8, 2]  比较 8,2 → 交换 → [3, 5, 4, 2, 8] ✓

第二轮（将第二大值 5 冒到倒数第二）:
[3, 5, 4, 2, 8]  比较 3,5 → 不换
[3, 5, 4, 2, 8]  比较 5,4 → 交换 → [3, 4, 5, 2, 8]
[3, 4, 5, 2, 8]  比较 5,2 → 交换 → [3, 4, 2, 5, 8] ✓

第三轮:
[3, 4, 2, 5, 8]  → [3, 2, 4, 5, 8] ✓

第四轮:
[3, 2, 4, 5, 8]  → [2, 3, 4, 5, 8] ✓

完成!
```

## 三、算法步骤

### 3.1 基本步骤

1. 从第一个元素开始，比较相邻的两个元素
2. 如果前面的比后面的大，则交换它们
3. 对每一对相邻元素重复步骤2，直到最后一对
4. 一轮结束后，最大的元素已在最后
5. 对剩余元素重复步骤1-4

### 3.2 伪代码

```
for i = 0 to n-2:
    for j = 0 to n-2-i:
        if arr[j] > arr[j+1]:
            swap(arr[j], arr[j+1])
```

## 四、代码实现

### 4.1 基本版本

```cpp
#include <iostream>
using namespace std;

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {           // n-1 轮
        for (int j = 0; j < n - 1 - i; j++) {   // 每轮比较次数递减
            if (arr[j] > arr[j + 1]) {
                // 交换
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[] = {5, 3, 8, 4, 2};
    int n = 5;

    cout << "排序前: ";
    printArray(arr, n);

    bubbleSort(arr, n);

    cout << "排序后: ";
    printArray(arr, n);

    return 0;
}
```

### 4.2 优化版本：提前终止

如果某一轮没有发生交换，说明数组已经有序，可以提前结束。

```cpp
void bubbleSortOptimized(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;  // 标记是否发生交换

        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }

        if (!swapped) {  // 没有交换，已有序
            break;
        }
    }
}
```

## 五、详细步骤追踪

对 `[5, 1, 4, 2, 8]` 进行冒泡排序：

```
初始: [5, 1, 4, 2, 8]

=== 第1轮 ===
比较 5,1: 5>1, 交换 → [1, 5, 4, 2, 8]
比较 5,4: 5>4, 交换 → [1, 4, 5, 2, 8]
比较 5,2: 5>2, 交换 → [1, 4, 2, 5, 8]
比较 5,8: 5<8, 不换 → [1, 4, 2, 5, 8]
第1轮结束: [1, 4, 2, 5, 8]  // 8已在最后

=== 第2轮 ===
比较 1,4: 1<4, 不换 → [1, 4, 2, 5, 8]
比较 4,2: 4>2, 交换 → [1, 2, 4, 5, 8]
比较 4,5: 4<5, 不换 → [1, 2, 4, 5, 8]
第2轮结束: [1, 2, 4, 5, 8]  // 5已在正确位置

=== 第3轮 ===
比较 1,2: 1<2, 不换
比较 2,4: 2<4, 不换
第3轮结束: [1, 2, 4, 5, 8]  // 无交换，可提前结束

排序完成: [1, 2, 4, 5, 8]
```

## 六、时间复杂度分析

### 6.1 最好情况

数组已经有序（使用优化版本）：

- 只需一轮，比较 n-1 次，无交换
- 时间复杂度：**O(n)**

### 6.2 最坏情况

数组完全逆序：

- 需要 n-1 轮
- 总比较次数：(n-1) + (n-2) + ... + 1 = n(n-1)/2
- 时间复杂度：**O(n²)**

### 6.3 平均情况

- 时间复杂度：**O(n²)**

### 6.4 空间复杂度

- 只需要一个临时变量用于交换
- 空间复杂度：**O(1)**

## 七、稳定性分析

### 7.1 冒泡排序是稳定的

```
原数组: [3a, 2, 3b, 1]

排序过程中，相等的元素不会交换位置
（只有 arr[j] > arr[j+1] 时才交换）

排序后: [1, 2, 3a, 3b]  // 3a 仍在 3b 前面
```

## 八、冒泡排序的特点

### 8.1 优点

✅ 简单直观，易于理解和实现
✅ 稳定排序
✅ 原地排序，不需要额外空间
✅ 对几乎有序的数组效率高（优化版）

### 8.2 缺点

❌ 时间复杂度 O(n²)，对大数据量效率低
❌ 比较和交换次数多

### 8.3 与其他 O(n²) 排序对比

| 算法     | 平均时间 | 最好时间 | 稳定性 | 特点             |
| -------- | -------- | -------- | ------ | ---------------- |
| 冒泡排序 | O(n²)    | O(n)     | ✓      | 最直观           |
| 选择排序 | O(n²)    | O(n²)    | ×      | 交换次数少       |
| 插入排序 | O(n²)    | O(n)     | ✓      | 对基本有序数组快 |

## 九、例题精讲

### 例题1：统计交换次数

```cpp
#include <iostream>
using namespace std;

int bubbleSortCount(int arr[], int n) {
    int swapCount = 0;

    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapCount++;
            }
        }
    }

    return swapCount;
}

int main() {
    int arr[] = {5, 4, 3, 2, 1};
    int n = 5;

    cout << "交换次数: " << bubbleSortCount(arr, n) << endl;
    // 逆序数组，交换次数最多：10次

    return 0;
}
```

### 例题2：求逆序对数量

冒泡排序的交换次数 = 逆序对数量

```cpp
#include <iostream>
using namespace std;

long long countInversions(int arr[], int n) {
    long long count = 0;
    int temp[1010];

    // 复制数组
    for (int i = 0; i < n; i++) temp[i] = arr[i];

    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (temp[j] > temp[j + 1]) {
                swap(temp[j], temp[j + 1]);
                count++;
            }
        }
    }

    return count;
}

int main() {
    int arr[] = {3, 1, 2};
    int n = 3;

    cout << "逆序对数量: " << countInversions(arr, n) << endl;
    // (3,1), (3,2) = 2对

    return 0;
}
```

## 十、冒泡排序的变体

### 10.1 鸡尾酒排序（双向冒泡）

```cpp
void cocktailSort(int arr[], int n) {
    int left = 0, right = n - 1;

    while (left < right) {
        // 从左到右，把最大的冒到右边
        for (int i = left; i < right; i++) {
            if (arr[i] > arr[i + 1]) {
                swap(arr[i], arr[i + 1]);
            }
        }
        right--;

        // 从右到左，把最小的冒到左边
        for (int i = right; i > left; i--) {
            if (arr[i] < arr[i - 1]) {
                swap(arr[i], arr[i - 1]);
            }
        }
        left++;
    }
}
```
