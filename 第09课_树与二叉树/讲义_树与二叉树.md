## 三、树的基本概念

### 3.1 什么是树？

**树**是由 n（n≥0）个节点组成的有限集合，满足：

- 有且仅有一个**根节点**
- 其余节点分成若干个**子树**

### 3.2 树的术语

```
        A          ← 根节点（Root）
       /|\
      B C D        ← A的子节点
     /|   |
    E F   G        ← 叶子节点（没有子节点）
```

| 术语     | 说明                         | 示例            |
| -------- | ---------------------------- | --------------- |
| 根节点   | 没有父节点的节点             | A               |
| 父节点   | 某节点的上一层节点           | B 是 E 的父节点 |
| 子节点   | 某节点的下一层节点           | E 是 B 的子节点 |
| 兄弟节点 | 同一父节点的节点             | E 和 F 是兄弟   |
| 叶子节点 | 没有子节点的节点             | E, F, C, G      |
| 深度     | 从根到该节点的路径长度       | B 的深度是 1    |
| 高度     | 从该节点到最远叶子的路径长度 | A 的高度是 2    |

### 3.3 树的高度和深度

```
深度 0:      A
            / \
深度 1:    B   C
          / \
深度 2:  D   E

高度 = 最大深度 = 2
```

## 四、二叉树

### 4.1 什么是二叉树？

**二叉树**：每个节点最多有 **2 个子节点**（左子节点和右子节点）

```
      1
     / \
    2   3
   / \   \
  4   5   6
```

### 4.2 二叉树的特点

- 每个节点最多有 2 个子节点
- 左子树和右子树是有区别的（有序的）
- 即使只有一个子节点，也要区分是左还是右

### 4.3 特殊的二叉树

**满二叉树**：每一层都是满的

```
       1
      / \
     2   3
    /|   |\
   4 5   6 7
```

**完全二叉树**：除最后一层外，其他层都是满的，最后一层的节点从左到右连续

```
       1
      / \
     2   3
    / \  /
   4  5 6
```

## 五、二叉树的存储

### 5.1 数组存储（适合完全二叉树）

对于编号从 1 开始的完全二叉树，设父节点索引为 `i`：

- 左子节点：`i * 2`
- 右子节点：`i * 2 + 1`

```cpp
//        1
//       / \
//      2   3
//     / \
//    4   5

int tree[10] = {0, 1, 2, 3, 4, 5};  // 下标从1开始
// tree[1] = 1 (根)
// tree[2] = 2 (1的左子)
// tree[3] = 3 (1的右子)
// tree[4] = 4 (2的左子)
// tree[5] = 5 (2的右子)
```

### 5.2 链式存储（适合所有二叉树）

```cpp
struct TreeNode {
    int val;           // 节点值
    TreeNode* left;    // 左子节点
    TreeNode* right;   // 右子节点

    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

### 5.3 创建二叉树示例

```cpp
#include <iostream>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

int main() {
    // 创建二叉树:
    //       1
    //      / \
    //     2   3
    //    / \
    //   4   5

    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);

    cout << "根节点: " << root->val << endl;
    cout << "左子节点: " << root->left->val << endl;
    cout << "右子节点: " << root->right->val << endl;

    return 0;
}
```

## 六、⭐ 二叉树的遍历

### 6.1 三种遍历方式

| 遍历方式 | 顺序     | 记忆口诀 |
| -------- | -------- | -------- |
| 前序遍历 | 根→左→右 | 根在前   |
| 中序遍历 | 左→根→右 | 根在中   |
| 后序遍历 | 左→右→根 | 根在后   |

### 6.2 遍历示例

```
       1
      / \
     2   3
    / \
   4   5

前序遍历: 1, 2, 4, 5, 3  （先访问根，再左子树，再右子树）
中序遍历: 4, 2, 5, 1, 3  （先左子树，再根，再右子树）
后序遍历: 4, 5, 2, 3, 1  （先左子树，再右子树，再根）
```

### 6.3 递归实现

```cpp
#include <iostream>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

// 前序遍历：根 → 左 → 右
void preorder(TreeNode* root) {
    if (root == nullptr) return;

    cout << root->val << " ";  // 访问根
    preorder(root->left);       // 遍历左子树
    preorder(root->right);      // 遍历右子树
}

// 中序遍历：左 → 根 → 右
void inorder(TreeNode* root) {
    if (root == nullptr) return;

    inorder(root->left);        // 遍历左子树
    cout << root->val << " ";  // 访问根
    inorder(root->right);       // 遍历右子树
}

// 后序遍历：左 → 右 → 根
void postorder(TreeNode* root) {
    if (root == nullptr) return;

    postorder(root->left);      // 遍历左子树
    postorder(root->right);     // 遍历右子树
    cout << root->val << " ";  // 访问根
}

int main() {
    // 创建二叉树
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);

    cout << "前序遍历: ";
    preorder(root);
    cout << endl;

    cout << "中序遍历: ";
    inorder(root);
    cout << endl;

    cout << "后序遍历: ";
    postorder(root);
    cout << endl;

    return 0;
}
```

**输出**：

```
前序遍历: 1 2 4 5 3
中序遍历: 4 2 5 1 3
后序遍历: 4 5 2 3 1
```

### 6.4 遍历的理解技巧

**画圈法**：

1. 从根节点出发，沿着树的外沿画一圈
2. 前序：第一次经过节点左侧时访问
3. 中序：第一次经过节点下方时访问
4. 后序：第一次经过节点右侧时访问

## 七、二叉树的常见操作

### 7.1 计算节点数

```cpp
int countNodes(TreeNode* root) {
    if (root == nullptr) return 0;
    return 1 + countNodes(root->left) + countNodes(root->right);
}
```

### 7.2 计算高度

```cpp
int getHeight(TreeNode* root) {
    if (root == nullptr) return 0;
    return 1 + max(getHeight(root->left), getHeight(root->right));
}
```

### 7.3 查找节点

```cpp
TreeNode* search(TreeNode* root, int target) {
    if (root == nullptr) return nullptr;
    if (root->val == target) return root;

    TreeNode* leftResult = search(root->left, target);
    if (leftResult != nullptr) return leftResult;

    return search(root->right, target);
}
```

### 7.4 统计叶子节点

```cpp
int countLeaves(TreeNode* root) {
    if (root == nullptr) return 0;
    if (root->left == nullptr && root->right == nullptr) {
        return 1;  // 是叶子节点
    }
    return countLeaves(root->left) + countLeaves(root->right);
}
```

## 八、经典递归代码练习

通过以下四个经典练习，深入体会“递归”与“树”的紧密联系。

### 8.1 练习一：斐波那契数列（递归树）

计算 `fib(n)` 的过程本质上是在构建一棵二叉树。

```cpp
int fib(int n) {
    if (n <= 1) return n;
    // 每次调用分裂成两个子任务，就像树的分叉
    return fib(n - 1) + fib(n - 2);
}
```

### 8.2 练习二：汉诺塔问题 (Hanoi)

经典的递归问题。虽然不是直接操作二叉树，但其函数调用过程是一棵完美的二叉树。

```cpp
// 将 n 个盘子从 A 柱移到 C 柱，利用 B 柱
void hanoi(int n, char A, char B, char C) {
    if (n == 1) {
        cout << "Move disk 1 from " << A << " to " << C << endl;
        return;
    }
    hanoi(n - 1, A, C, B); // 将 n-1 个盘子从 A 移到 B
    cout << "Move disk " << n << " from " << A << " to " << C << endl;
    hanoi(n - 1, B, A, C); // 将 n-1 个盘子从 B 移到 C
}
```

### 8.3 练习三：翻转二叉树

将二叉树的所有左右子树交换（镜像翻转）。

```cpp
void invertTree(TreeNode* root) {
    if (root == nullptr) return;

    // 1. 交换当前节点的左右孩子
    swap(root->left, root->right);

    // 2. 递归翻转左子树
    invertTree(root->left);

    // 3. 递归翻转右子树
    invertTree(root->right);
}
```

### 8.4 练习四：判断两棵树是否相同

递归比较两棵树的结构和值是否完全一致。

```cpp
bool isSameTree(TreeNode* p, TreeNode* q) {
    // 1. 都为空，相同
    if (p == nullptr && q == nullptr) return true;

    // 2. 一个为空一个不空，不同
    if (p == nullptr || q == nullptr) return false;

    // 3. 值不同，不同
    if (p->val != q->val) return false;

    // 4. 递归比较左右子树
    return isSameTree(p->left, q->left) &&
           isSameTree(p->right, q->right);
}
```

## 九、用数组模拟二叉树

对于完全二叉树，用数组存储非常高效：

```cpp
#include <iostream>
using namespace std;

class ArrayTree {
private:
    int tree[100];
    int size;

public:
    ArrayTree() : size(0) {
        fill(tree, tree + 100, 0);
    }

    // 添加节点
    void add(int val) {
        tree[++size] = val;
    }

    // 获取父节点
    int parent(int i) {
        return tree[i / 2];
    }

    // 获取左子节点
    int left(int i) {
        return 2 * i <= size ? tree[2 * i] : -1;
    }

    // 获取右子节点
    int right(int i) {
        return 2 * i + 1 <= size ? tree[2 * i + 1] : -1;
    }

    // 前序遍历
    void preorder(int i) {
        if (i > size || tree[i] == 0) return;
        cout << tree[i] << " ";
        preorder(2 * i);
        preorder(2 * i + 1);
    }

    // 中序遍历
    void inorder(int i) {
        if (i > size || tree[i] == 0) return;
        inorder(2 * i);
        cout << tree[i] << " ";
        inorder(2 * i + 1);
    }
};

int main() {
    ArrayTree tree;
    tree.add(1);
    tree.add(2);
    tree.add(3);
    tree.add(4);
    tree.add(5);

    cout << "前序遍历: ";
    tree.preorder(1);
    cout << endl;

    cout << "中序遍历: ";
    tree.inorder(1);
    cout << endl;

    return 0;
}
```

## 十、本课小结

### 核心概念

| 概念   | 说明                   |
| ------ | ---------------------- |
| 树     | 层次结构的数据组织方式 |
| 二叉树 | 每个节点最多两个子节点 |
| 遍历   | 按特定顺序访问所有节点 |
| 递归   | 树的自然处理方式       |

### 三种遍历

| 遍历 | 顺序     | 应用场景         |
| ---- | -------- | ---------------- |
| 前序 | 根→左→右 | 复制树、快速排序 |
| 中序 | 左→根→右 | 二叉搜索树排序   |
| 后序 | 左→右→根 | 删除树、归并排序 |
