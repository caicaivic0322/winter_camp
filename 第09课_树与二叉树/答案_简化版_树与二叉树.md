# 📝 第9课 答案与解析：树与二叉树

## 一、选择题（每题5分，共40分）

1. **B**
   **解析**：根节点是树的起始节点，没有父节点。

2. **B**
   **解析**：二叉树的定义就是每个节点最多有两个子节点（左孩子和右孩子）。

3. **B**
   **解析**：前序遍历顺序：根 -> 左 -> 右。图示根是1，左是2，右是3。结果：1, 2, 3。

4. **B**
   **解析**：中序遍历顺序：左子树 -> 根节点 -> 右子树。

5. **B**
   **解析**：代码顺序是 `traverse(left)` -> `visit(root)` -> `traverse(right)`，即 左-根-右，中序遍历。

6. **B**
   **解析**：满二叉树定义：所有分支节点都有左右子节点，且所有叶子节点都在同一层。（或者定义为深度为k且有 $2^k-1$ 个节点）。每一层都是满的。

7. **A**
   **解析**：斐波那契递归 `fib(n) = fib(n-1) + fib(n-2)` 会对相同的子问题进行多次重复计算。

8. **C**
   **解析**：汉诺塔移动次数公式是 $2^n - 1$。

## 二、判断题（每题5分，共20分）

1. **×**
   **解析**：二叉树是有序树，左右子树严格区分，不能随意互换。互换后变成另一棵二叉树。

2. **√**
   **解析**：前序遍历（根左右），第一个访问的必然是根。

3. **√**
   **解析**：完全二叉树节点紧凑，适合用数组存储（下标关系 `2i`, `2i+1`）。

4. **×**
   **解析**：树的高度是层数，节点个数取决于树的形态。例如一条链，高度=节点数；满二叉树，节点数指数增长。

## 三、程序完善题（共40分）

### 第1题（10分）

① `nullptr`
② `val`
③ `left`
④ `right`

**解析**：

- ① 递归终止条件：当前节点为空。
- ② 访问操作：输出当前节点的值 `val`。
- ③ 递归遍历左子树。
- ④ 递归遍历右子树。

### 第2题

① `0`
② `left`
③ `right`
④ `1`

**解析**：

- ① 空节点，数量为 0。
- ② 统计左子树节点数。
- ③ 统计右子树节点数。
- ④ 总数 = 根节点(1) + 左子树数 + 右子树数。

### 第3题（20分）

① `n - 1`
② `B`
③ `A`
④ `C`

**解析**：

- ① 先把上面的 n-1 个盘子从 A 移到 B。
- ②③④ 把这 n-1 个盘子从 B 移到 C（辅助柱是 A）。也就是 `hanoi(n-1, B, A, C)`。
