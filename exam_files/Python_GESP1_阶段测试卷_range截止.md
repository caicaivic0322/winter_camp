### 第1题：读取整数并计算平方

**题目描述：** 输入一个整数，输出它的平方。

```python
n = ______①
print(n ** 2)
```

**① 的备选项：**
A. `input()`
B. `int(input())`
C. `float`
D. `print(input())`

### 第2题：补全平均数计算

**题目描述：** 输入两个整数，输出它们的平均数。

```python

b = int(input())
avg = ______②

```

**② 的备选项：**

D. `a % b`

### 第3题：判断是否为正数
