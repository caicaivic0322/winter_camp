### 第2题：补全优先级正确的平均数计算

### 第3题：判断是否在区间内（链式比较）

**题目描述：** 输入一个整数 `x`，若 `x` 在 10 到 99 之间（包含 10 和 99），输出“是两位数”。

```python
x = int(input())
if ______③:
    print("是两位数")
```

**③ 的备选项：**  
A. `x >= 10 and x <= 99`  
B. `10 <= x <= 99`  
C. `x > 10 and x < 99`  
D. `x == 10 or 99`  

> 说明：本题按 Python 表达式书写的规范性评分，最佳答案只有一个。

### 第8题：成绩分段判断

**题目描述：** 输入一个分数 `score`。若分数大于等于 90，输出“优秀”；若分数大于等于 60 且小于 90，输出“及格”；否则输出“不及格”。

```python
score = int(input())
if score >= 90:
    print("优秀")
elif ______⑧:
    print("及格")
else:
    print("不及格")
```

**⑧ 的备选项：**  
A. `score >= 60`  
B. `score > 60 and score < 90`  
C. `60 <= score < 90`  
D. `score >= 60 and score <= 90`
