**2.** 在 Python 中，变量名可以以数字开头。（　×　）  

**3.** `input()` 读入的数据默认是字符串类型。（　√　）  

**4.** 表达式 `7 // 2` 的值是 `3`。（　√　）  

**5.** 在 Python 中，幂运算按从右向左的顺序结合，所以代码 `print(2 ** 3 ** 2)` 的输出不是 `64`，而是 `512`。（　√　）  

**6.** 当 `x = 2` 时，表达式 `1 < x < 3` 的值为 `True`。（　√　）  

**7.** 表达式 `3 + 2 * 5` 的值是 `25`。（　×　）  

**8.** 在 `if-elif-else` 结构中，只会进入其中一个分支执行。（　√　）  

**9.** `range(1, 5)` 生成的序列中不包含 `5`。（　√　）  

**10.** 设 `x = 7`，则表达式 `x > 10 and x % 2 == 1` 的值是 `True`。（　×　）

## 三、完善程序题（每题 5 分，共 40 分）

### 第1题：输入两个整数并输出和

**题目描述：** 输入两个整数，输出它们的和。

```python
a = int(input())
b = int(input())
print(______①)
```

**① 的备选项：**  
A. `a - b`  
B. `a + b`  
C. `a * b`  
D. `a / b`  

### 第2题：计算平均数

**题目描述：** 输入两个整数，输出它们的平均数。要求先求和，再除以 `2`。

```python
a = int(input())
b = int(input())
avg = ______②
print(avg)
```

**② 的备选项：**  
A. `a + b / 2`  
B. `(a + b) / 2`  
C. `(a + b) // 2`  
D. `a % b`  

### 第3题：判断一个数是否在区间内

**题目描述：** 输入一个整数 `x`，若 `x` 在 `10` 到 `99` 之间（含两端），输出 `yes`。

```python
x = int(input())
if ______③:
    print("yes")
```

**③ 的备选项：**  
A. `10 <= x <= 99`  
B. `x < 10 or x > 99`  
C. `10 < x < 99 or x == 100`  
D. `x == 10 and x == 99`  

### 第4题：根据成绩分档

**题目描述：** 输入成绩 `score`。若成绩大于等于 `90`，输出 `优秀`；否则输出 `继续努力`。

```python
score = int(input())
if ______④:
    print("优秀")
else:
    print("继续努力")
```

**④ 的备选项：**  
A. `score > 90`  
B. `score >= 90`  
C. `score = 90`  
D. `score <= 90`  

### 第5题：统计 1 到 n 的和

**题目描述：** 输入一个正整数 `n`，计算 `1 + 2 + ... + n`。

```python
n = int(input())
s = 0
for i in ______⑤:
    s += i
print(s)
```

**⑤ 的备选项：**  
A. `range(n)`  
B. `range(1, n)`  
C. `range(1, n + 1)`  
D. `range(n + 1)`  

### 第6题：统计偶数个数

**题目描述：** 统计 `1` 到 `10` 中偶数的个数。

```python
count = 0
for i in range(1, 11):
    if i % 2 == 0:
        count = count + ______⑥
print(count)
```

**⑥ 的备选项：**  
A. `0`  
B. `1`  
C. `i`  
D. `2`  

### 第7题：按条件输出结果

**题目描述：** 输入一个整数 `n`。若 `n` 能被 `3` 整除且能被 `5` 整除，则输出 `OK`。

```python
n = int(input())
if ______⑦:
    print("OK")
```

**⑦ 的备选项：**  
A. `n % 3 == 0 or n % 5 == 0`  
B. `n % 3 == 0 and n % 5 == 0`  
C. `n % 15 == 1`  
D. `n // 3 == 0 and n // 5 == 0`  

### 第8题：根据范围分类

**题目描述：** 输入一个整数 `x`。若 `x` 小于 `0`，输出 `负数`；若 `x` 等于 `0`，输出 `零`；否则输出 `正数`。

```python
x = int(input())
if x < 0:
    print("负数")
elif ______⑧:
    print("零")
else:
    print("正数")
```

**⑧ 的备选项：**  
A. `x = 0`  
B. `x == 0`  
C. `x <= 0`  
D. `x >= 0`
