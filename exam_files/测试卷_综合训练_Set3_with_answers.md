### 第1题：归并两个有序区间

**题目描述**：已知 `a[l..mid]` 和 `a[mid+1..r]` 都已经有序，下面程序将它们合并到临时数组 `tmp` 中。  

```cpp
void merge(int a[], int l, int mid, int r) {
    int tmp[200];
    int i = l, j = mid + 1, k = 0;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            tmp[k++] = ______①;
        }
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = 0; t < k; t++) {
        a[l + t] = ______②;
    }
}
```

**① 的备选项：**  
A. `a[i++]`  
_B._ `a[j++]`  
C. `a[j]`  
D. `tmp[j++]`  

**② 的备选项：**  
A. `a[t]`  
_B._ `tmp[t]`  
C. `tmp[l + t]`  
D. `a[l + t]`
