### 第31题：输出个位数字

**题目描述：** 输入一个两位整数 `n`，输出它的个位数字。

```python
n = int(input())
print(______①)
```

**① 的备选项：**
A. `n // 10`
B. `n % 10`
C. `n / 10`
D. `10 % n`
