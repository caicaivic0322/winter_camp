### 第1题：读取整数并计算平方

**题目描述：** 输入一个整数，输出它的平方。

```python
n = ______①
print(n ** 2)
```

**① 的备选项：**
A. `input()`
B. `int(input())`
C. `float`
D. `print(input())`

---

### 第2题：补全运算优先级正确的表达式

**题目描述：** 输入两个整数 `a` 和 `b`，输出它们的平均数。

```python
a = int(input())
b = int(input())
avg = ______②
print(avg)
```

**② 的备选项：**
A. `a + b / 2`
B. `(a + b) / 2`
C. `a // b`
D. `a % b`

---

### 第3题：判断是否在区间内

**题目描述：** 输入一个整数 `x`，若 `x` 在 1 到 9 之间（包含 1 和 9），输出“是个位数”。

```python
x = int(input())
if ______③:
    print("是个位数")
```

**③ 的备选项：**
A. `x > 1 and x < 9`
B. `1 <= x <= 9`
C. `x == 1 or 9`
D. `x >= 10`

---

result = ______④
