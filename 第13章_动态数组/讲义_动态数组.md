# 📘 第13章 动态数组

> 目标：熟练使用 `vector` 与 `string`，理解动态与静态数组的差异

---

## 13.1 vector 容器
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {3,1,4};
    v.push_back(1);
    sort(v.begin(), v.end());
    for (int x : v) cout << x << " ";
    cout << "\nsize=" << v.size() << endl;
    return 0;
}
```
- 动态扩容、`push_back`、迭代器 `begin()/end()`、`size()`

## 13.2 string 类
```cpp
string s = "hello";
s += " world";
auto pos = s.find("lo");      // 返回下标或 string::npos
if (pos != string::npos) s.replace(pos, 2, "LO");
```

---

## 13.3 动态数组与静态数组的对比
- 静态数组：大小固定、栈上分配；`int a[100]`
- 动态数组：可变长度、堆上分配；`vector<int> v`
- 竞赛中优先使用 `vector`，更灵活安全
