## 22.1 基本概念与表示
- 有向图/无向图、权值、邻接表/邻接矩阵
```cpp
const int N = 100005;
vector<int> g[N];      // 邻接表
int n, m;
for (int i = 0; i < m; i++) {
    int u, v; cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u); // 无向图
}
```

## 22.2 图的遍历算法
DFS：
```cpp
vector<int> g[N]; bool vis[N];
void dfs(int u) {
    vis[u] = true;
    for (int v : g[u]) if (!vis[v]) dfs(v);
}
```
BFS：
```cpp
int dist[N]; // 初始化为 -1
queue<int> q; dist[s] = 0; q.push(s);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) if (dist[v] == -1) {
        dist[v] = dist[u] + 1; q.push(v);
    }
}
```

- 使用 BFS，`dist[v]` 即为最少边数

## 22.4 图的连通性
- 使用 DFS/BFS 统计连通块个数
```cpp
int comp = 0;
for (int i = 1; i <= n; i++) if (!vis[i]) { dfs(i); comp++; }
```

## 22.5 并查集（DSU）
```cpp
int fa[N];
int find(int x){ return x==fa[x]?x:fa[x]=find(fa[x]); }
void unite(int a,int b){ a=find(a); b=find(b); if(a!=b) fa[a]=b; }
```
- 作用：快速合并/查询是否在同一连通块

---

## 22.6 最小生成树（Kruskal）
```cpp
struct E{int u,v,w;};
vector<E> edges; sort(edges.begin(), edges.end(), [](auto& a, auto& b){return a.w<b.w;});
int ans=0,cnt=0;
for (auto &e: edges){
    if (find(e.u)!=find(e.v)) { unite(e.u,e.v); ans+=e.w; cnt++; }
}
```
