## 二、深度优先搜索 (DFS)

### 2.1 核心思想

**不撞南墙不回头**。一条路走到黑，走不通了再回溯。

### 2.2 典型应用

- 迷宫寻找路径（是否存在）
- 排列组合
- 连通性判断

### 2.3 代码模板 (递归)

```cpp
bool visited[100];
void dfs(int u) {
    if (visited[u]) return;
    visited[u] = true;
    cout << "访问: " << u << endl;

    for (int v : adj[u]) { // 遍历邻居
        dfs(v);
    }
}
```

## 三、广度优先搜索 (BFS)

### 3.1 核心思想

**层层递进**。先访问离起点最近的点，再访问稍远的。

### 3.2 典型应用

- **最短路径**（无权图）
- 层序遍历

### 3.3 代码模板 (队列)

```cpp
void bfs(int start) {
    queue<int> q;
    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        cout << "访问: " << u << endl;

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
}
```

## 四、经典问题：迷宫最短路 (BFS)

**问题**：给定一个 N*M 的迷宫，0 表示路，1 表示墙。求从左上角到右下角的最少步数。

```cpp
#include <iostream>
#include <queue>
using namespace std;

struct Node { int x, y, step; };
int dx[] = {0, 0, 1, -1};
int dy[] = {1, -1, 0, 0};
int map[100][100];
bool visited[100][100];
int n, m;

int bfs(int sx, int sy, int ex, int ey) {
    queue<Node> q;
    q.push({sx, sy, 0});
    visited[sx][sy] = true;

    while (!q.empty()) {
        Node curr = q.front();
        q.pop();

        if (curr.x == ex && curr.y == ey) return curr.step;

        for (int i = 0; i < 4; i++) {
            int nx = curr.x + dx[i];
            int ny = curr.y + dy[i];

            if (nx >= 0 && nx < n && ny >= 0 && ny < m && !map[nx][ny] && !visited[nx][ny]) {
                visited[nx][ny] = true;
                q.push({nx, ny, curr.step + 1});
            }
        }
    }
    return -1;
}
```

## 五、经典问题：全排列 (DFS)

**问题**：输出 1 到 N 的全排列。

```cpp
int n;
int path[10];
bool used[10];

void dfs(int u) {
    if (u == n) {
        for (int i = 0; i < n; i++) cout << path[i] << " ";
        cout << endl;
        return;
    }

    for (int i = 1; i <= n; i++) {
        if (!used[i]) {
            path[u] = i;
            used[i] = true;
            dfs(u + 1);
            used[i] = false; // 回溯
        }
    }
}
```

## 六、DFS vs BFS

| 特性 | DFS | BFS |
| --- | --- | --- |
| 数据结构 | 栈 (递归) | 队列 |
| 路径特性 | 不一定最短 | **最短路径** (无权图) |
| 空间复杂度 | O(h) (树高) | O(w) (树宽) |
| 适用场景 | 排列组合、连通性 | 最短路、层序遍历 |

## 七、随堂练习

### 练习 1：岛屿数量 (DFS/BFS)

**题目**：给你一个由 '1'（陆地）和 '0'（水）组成的的二维网格，请你计算网格中岛屿的数量。岛屿总是被水包围，并且每座岛屿只能由水平方向和/或竖直方向上相邻的陆地连接形成。

**思路**：遍历网格，每遇到一个 '1'，就将计数器加 1，并启动 DFS 或 BFS 将与它相连的所有 '1' 标记为已访问（或者直接修改为 '0'）。

```cpp
void dfs(vector<vector<char>>& grid, int r, int c) {
    int nr = grid.size();
    int nc = grid[0].size();
    grid[r][c] = '0'; // 标记已访问
    
    int dx[] = {0, 0, 1, -1};
    int dy[] = {1, -1, 0, 0};
    
    for (int i = 0; i < 4; i++) {
        int x = r + dx[i], y = c + dy[i];
        if (x >= 0 && x < nr && y >= 0 && y < nc && grid[x][y] == '1') {
            dfs(grid, x, y);
        }
    }
}
```

### 练习 2：腐烂的橘子 (BFS)

**题目**：在给定的网格中，每个单元格可以有以下三个值之一：
- 0 代表空单元格；
- 1 代表新鲜橘子；
- 2 代表腐烂的橘子。
每分钟，任何与腐烂橘子（在 4 个正方向上）相邻的新鲜橘子都会腐烂。返回直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 -1。

**思路**：多源 BFS。先将所有一开始腐烂的橘子加入队列，然后层序遍历，每扩展一层时间加 1。

## 八、本课小结

1. **DFS**：递归回溯，适合找可行解。
2. **BFS**：队列层序，适合找最短路。
3. **图的遍历**：这是所有高级图算法（Dijkstra, Prim）的基础。
