# 考试 Markdown 导入模板说明

以后出题建议严格按下面规则写，这样可以稳定导入：

## 1. 文件结构

推荐顺序：

1. Frontmatter（可选）
2. `## 一、单选题`
3. `## 二、判断题`
4. `## 三、程序完善题`
5. `## 参考答案汇总`

## 2. 单选题格式

```md
**1.** 题目内容（　　）
A. 选项 A
B. 选项 B
C. 选项 C
D. 选项 D
```

如果题目里有代码，代码块放在题干后面、选项前面：

````md
**2.** 阅读下面代码，输出结果是（　　）

```python
name = "Python"
print("Hello,", name)
```

A. `Hello,name`
B. `Hello, Python`
C. `"Hello, Python"`
D. 程序报错
````

## 3. 判断题格式

```md
**1.** 表达式 `2 ** 3 ** 2` 的值是 `64`。（　　）
```

不要把 `**` 当成普通文本粗暴删除。幂运算、乘方、Markdown 粗体是两回事。

## 4. 程序完善题格式

````md
### 第1题：题目标题

**题目描述：** 题目说明文字。

```python
n = ______①
print(n ** 2)
```

**① 的备选项：**
A. `input()`
B. `int(input())`
C. `float`
D. `print(input())`
````

注意：

- 每道程序完善题用 `### 第n题：标题`
- 每个空只能用 `①②③④⑤⑥⑦⑧⑨⑩`
- 备选项标题必须写成 `**① 的备选项：**`

## 5. 参考答案汇总格式

```md
## 参考答案汇总

**单选题：**
1.B　2.C　3.A

**判断题：**
1.√　2.×　3.√

**程序完善题：**
①B　②A　③C
```

建议统一把答案放在最后汇总，不要把正确答案混在题目选项里。

## 6. 推荐做法

- 选项里的代码或字符串，尽量用反引号包起来
- 如果字符串本身包含双引号，例如 `"Hello, Python"`，要完整保留
- 代码题一定使用 fenced code block，也就是三反引号
- 章节标题、题号、圈号、答案汇总标题尽量不要改写

## 7. 最稳妥的方式

后台“考试管理”里的“下载 Markdown 模板”已经更新。以后新增试卷时，建议先下载模板，再在模板上改题目内容。
