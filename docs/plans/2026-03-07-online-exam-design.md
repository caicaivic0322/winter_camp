# 在线考试系统技术规划文档 (2026-03-07)

## 1. 项目概览
为延安科创训练营增加在线考试板块，支持 Markdown 题库解析、实时答题、自动判分及错题归档功能。

### 核心特性
- **MD 解析**：将 Markdown 文件解析为在线单选、判断、选择填空题。
- **等级限制**：仅 `level >= 中阶` 的学生可参加。
- **考试限时**：管理员发起考试，限定时间段登录，答题限时 60 秒。
- **即时反馈**：提交后立即显示成绩与错题。
- **错题复习**：自动收录错题至错题集。

---

## 2. 总体架构

### 后端 (Node.js/Express)
- **身份认证**：统一注册登录至后端，支持角色 (Admin/User) 与等级 (初/中/高阶) 校验。
- **题库管理**：解析上传的 MD 文件并持久化。
- **考试控制**：管理考试场次（开始时间、结束时间、时长）。
- **判分引擎**：校验学生答案并记录结果。
- **考试成绩服务**：按考试记录保存成绩与错题分析。

### 前端 (React/Vite)
- **管理端**：题库上传页、考试发起页。
- **学生端**：考试列表页、在线答题页（倒计时控制）、考试成绩页。

## 3. 分阶段实施计划

### 第一阶段：身份认证与数据基础 (当前目标)
- [ ] 将前端 `localStorage` 登录逻辑迁移至后端 `/api/login` 和 `/api/register`。
- [ ] 统一用户等级校验逻辑。
- [ ] 建立 `questions.json` (题库) 和 `exams.json` (场次) 初始数据结构。

### 第二阶段：Markdown 解析与上传
- [ ] 定义 MD 题目规范（YAML Frontmatter + 内容块）。
- [ ] 实现后端解析器：解析 `single` (单选), `judge` (判断), `select_blank` (选择填空)。
- [ ] 管理员上传接口与简单预览界面。

### 第三阶段：考试流程开发
- [ ] 实现考试场次列表（检查等级与时间窗口）。
- [ ] 实现答题倒计时组件 (60s)。
- [ ] 实现自动判分逻辑并立即返回报告。

### 第四阶段：错题集与复习
- [ ] 实现错题自动落库逻辑。
- [ ] 开发考试成绩页面（列表页 + 详情页）。
- [ ] 增加“重做错题”模式。

---

## 4. API 设计 (核心接口)

### 管理端
- `POST /api/admin/banks/upload`：上传 MD 题库。
- `POST /api/admin/exams/create`：发起新的考试场次。

### 学生端
- `GET /api/exams/available`：获取当前可参加的考试。
- `POST /api/exams/:id/submit`：提交答案并获取结果。
- `GET /api/my/exam-results`：获取个人考试成绩列表。
