# 📘 第15章 指针

> 目标：理解指针本质（地址），掌握与数组/字符串/函数的结合使用

---

## 15.1 指针的概念
```cpp
int x = 10;
int* p = &x;           // p 保存 x 的地址
cout << *p << endl;    // 解引用，输出 10
```

---

## 15.2 指针与一维数组
```cpp
int a[5] = {1,2,3,4,5};
int* p = a;            // a 是首元素地址
cout << *(p+2) << endl;// 3
```

---

## 15.3 指针与字符串
```cpp
char s[] = "abc";
char* ps = s;
while (*ps) {          // 遇到 '\0' 结束
    putchar(*ps);
    ps++;
}
```

---

## 15.4 指针与函数
```cpp
void inc(int* p) { (*p)++; }
int main() {
    int x = 5;
    inc(&x);
    cout << x << endl; // 6
}
```

---

## 15.5 引用与指针传参的对比
```cpp
void add_ref(int& x) { x++; }   // 引用更安全，语义清晰
void add_ptr(int* x) { (*x)++; }
```
- 能用引用时优先引用；需要可空/可重绑定时使用指针
